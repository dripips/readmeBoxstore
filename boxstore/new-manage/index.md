# index

## 📄 Документация по файлу `index.php` (АдминПанель)

Файл `index.php` является точкой входа веб-приложения **АдминПанель**, написанного на PHP. Он отвечает за настройку окружения, управление сессиями, проверку авторизации и маршрутизацию запросов. Документация описывает структуру, функциональность и назначение файла в контексте административной панели.

***

### 🚀 Обзор

Файл `index.php` выполняет следующие задачи:

* Настройка PHP-окружения (временная зона, отображение ошибок).
* Инициализация сессии для отслеживания авторизации пользователя.
* Подключение конфигурации и модуля безопасности.
* Маршрутизация запросов: отображение страниц логина/регистрации для неавторизованных пользователей или основного интерфейса для авторизованных.
* Подключение шаблонов и маршрутизатора для авторизованных пользователей.

***

### 📋 Структура и функциональность

#### 1. **Настройка окружения**

```php
date_default_timezone_set('Etc/GMT+3');
ini_set('display_errors', 1);
ini_set('display_startup_errors', 1);
error_reporting(E_ALL);
```

* **Описание**:
  * Устанавливает временную зону `Etc/GMT+3` для корректной работы функций даты и времени.
  * Включает отображение всех ошибок PHP (`E_ALL`), а также ошибок запуска и выполнения.
* **Назначение**: Обеспечивает единообразную обработку времени и отладку ошибок во время разработки.

***

#### 2. **Инициализация и зависимости**

```php
require_once 'config.php';
session_start();
require_once 'content/security/security.php';
```

* **Описание**:
  * Подключает файл конфигурации `config.php`, содержащий глобальные настройки приложения (например, `$config['site_path']`).
  * Запускает сессию с помощью `session_start()` для управления авторизацией.
  * Подключает модуль безопасности `content/security/security.php`, который, вероятно, содержит функции для защиты приложения.
* **Назначение**: Инициализирует базовые компоненты приложения и обеспечивает безопасность.

***

#### 3. **Маршрутизация**

```php
$path = $config['site_path'];

if (!isset($_SESSION['user'])) {
    if (isset($_GET['do']) && $_GET['do'] == 'register') {
        require include_once 'content/auth/register.php';
    } else {
        require_once 'content/auth/login.php';
    }
} else {
    $user = $_SESSION['user'];
    require_once 'content/function.php';
    require_once 'content/template/header.php';
    require_once 'content/router.php';
    require_once 'content/template/footer.php';
}
```

* **Описание**:
  * **Переменная `$path`**: Сохраняет базовый путь сайта из `$config['site_path']` для использования в шаблонах или маршрутизации.
  * **Логика маршрутизации**:
    * Если пользователь не авторизован (`$_SESSION['user']` не установлена):
      * При наличии параметра `$_GET['do'] == 'register'` подключается страница регистрации (`content/auth/register.php`).
      * В противном случае подключается страница логина (`content/auth/login.php`).
    * Если пользователь авторизован:
      * Сохраняет данные пользователя из `$_SESSION['user']` в переменную `$user`.
      * Подключает вспомогательные функции (`content/function.php`).
      * Подключает шаблон шапки (`content/template/header.php`).
      * Выполняет маршрутизацию через `content/router.php`.
      * Подключает шаблон подвала (`content/template/footer.php`).
* **Назначение**: Определяет, какой контент отображать в зависимости от статуса авторизации пользователя.

***

### 🔗 Зависимости

Файл зависит от следующих компонентов:

* **`config.php`**: Содержит массив `$config` с настройками приложения, включая `$config['site_path']`.
* **`content/security/security.php`**: Модуль безопасности, вероятно, реализующий функции защиты (например, проверка прав, фильтрация данных).
* **`content/auth/login.php`**: Страница входа, отображающая форму логина и обрабатывающая авторизацию.
* **`content/auth/register.php`**: Страница регистрации, отображающая форму создания нового пользователя.
* **`content/function.php`**: Вспомогательные функции для работы приложения.
* **`content/template/header.php`**: Шаблон шапки страницы (HTML-структура, стили, навигация).
* **`content/router.php`**: Маршрутизатор, определяющий контент на основе параметров запроса.
* **`content/template/footer.php`**: Шаблон подвала страницы (HTML-структура, скрипты).

***

### 📑 Роль в АдминПанели

Файл `index.php` выполняет следующие функции в контексте АдминПанели:

* **Точка входа**: Служит основным файлом, обрабатывающим все входящие HTTP-запросы.
* **Контроль доступа**: Проверяет авторизацию и направляет пользователей на соответствующие страницы (логин, регистрация, панель управления).
* **Инициализация интерфейса**: Подключает шаблоны и маршрутизатор для формирования страниц авторизованного интерфейса.
* **Интеграция**: Объединяет конфигурацию, безопасность и функциональные модули для работы приложения.

***

### ⚙️ Технические детали

* **Сессии**: Использует PHP-сессии для хранения данных пользователя (`$_SESSION['user']`).
* **Маршрутизация**: Основана на параметре `$_GET['do']` для неавторизованных пользователей и файле `router.php` для авторизованных.
* **Шаблонизация**: Применяет модульный подход с разделением на шапку (`header.php`), контент (`router.php`) и подвал (`footer.php`).
* **Ошибки**: Настроено отображение всех ошибок для упрощения отладки.
