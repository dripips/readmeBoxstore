# security

## 📄 Документация по файлу `security.php` (АдминПанель)

Файл `security.php`, расположенный в директории `content/security`, является частью веб-приложения **АдминПанель**. Он отвечает за инициализацию системы безопасности, связанной с проверкой авторизации пользователя и загрузкой его флагов доступа. Файл подключает классы `CSRF` и `UserFlags`, проверяет наличие авторизованного пользователя в сессии и загружает его флаги из базы данных. Документация описывает структуру, функциональность и назначение файла в контексте административной панели.

***

### 🚀 Обзор

Файл `security.php` выполняет следующие задачи:

* Подключает класс `CSRF` для защиты от атак межсайтовой подделки запросов.
* Проверяет наличие авторизованного пользователя в сессии (`$_SESSION['user']`).
* Загружает данные пользователя из сессии и извлекает его флаги доступа из базы данных.
* Создает объект `UserFlags` для управления разрешениями пользователя.
* Устанавливает основу для контроля доступа к модулям приложения, таким как создание или копирование заказов.

Файл является ключевым компонентом системы безопасности АдминПанели, обеспечивая проверку авторизации и прав доступа.

***

### 📋 Структура и функциональность

#### 1. **Подключение зависимостей**

```php
require_once 'CSRF.php';
```

* **Описание**:
  * Подключает файл `CSRF.php` из той же директории (`content/security`), который содержит класс `CSRF` для генерации и проверки CSRF-токенов.
* **Назначение**: Обеспечивает доступ к функциональности защиты от CSRF-атак для всех форм и AJAX-запросов в приложении.

***

#### 2. **Проверка авторизации и загрузка флагов**

```php
if (isset($_SESSION['user'])) {
    $user = $_SESSION['user'];
    // print_r($user);
    require_once 'flag.php';
    // Получаем флаги пользователя из БД
    $sql = "SELECT `flags_json` FROM orders_users WHERE id = :id";
    $stmt = $read->prepare($sql);
    $stmt->execute(['id' => $user['id']]);
    $user_flag = $stmt->fetch();
    $flags = new UserFlags($user_flag['flags_json']);
}
```

* **Описание**:
  * **Проверка авторизации**:
    * Проверяет наличие переменной `$_SESSION['user']`, которая указывает на авторизованного пользователя.
    * Если пользователь авторизован, извлекает его данные в переменную `$user` (предположительно массив с информацией, включая `id`).
  * **Закомментированный код**:
    * Содержит закомментированную строку `print_r($user);`, которая, вероятно, использовалась для отладки данных пользователя.
  * **Подключение `UserFlags`**:
    * Подключает файл `flag.php`, содержащий класс `UserFlags` для управления флагами доступа.
  * **Запрос к базе данных**:
    * Выполняет SQL-запрос к таблице `orders_users` для получения JSON-строки с флагами (`flags_json`) пользователя по его идентификатору (`id`).
    * Использует PDO-объект `$read` для подготовки и выполнения запроса с привязкой параметра `:id` к `$user['id']`.
    * Извлекает результат запроса в переменную `$user_flag` с помощью `fetch()`.
  * **Создание объекта `UserFlags`**:
    * Создает экземпляр класса `UserFlags`, передавая в конструктор строку `$user_flag['flags_json']`.
    * Объект `$flags` становится доступным для проверки прав доступа в других модулях.
* **Назначение**: Инициализирует данные пользователя и его флаги доступа, необходимые для контроля доступа к функционалу приложения.

***

### 🔗 Зависимости

Файл зависит от следующих компонентов:

* **Файлы**:
  * `CSRF.php`: Класс `CSRF` для управления CSRF-токенами, расположенный в `content/security`.
  * `flag.php`: Класс `UserFlags` для управления флагами доступа, расположенный в `content/security`.
* **Сессии**:
  * `$_SESSION['user']`: Переменная сессии, содержащая данные авторизованного пользователя (как минимум поле `id`).
* **База данных**:
  * PDO-объект `$read`: Предположительно определен в другом файле (например, `config.php` или `function.php`) и используется для запросов к базе данных.
  * Таблица `orders_users`: Содержит данные пользователей, включая поле `flags_json` с JSON-строкой флагов.
* **Модули АдминПанели**:
  * Используется в других файлах, таких как `ordersCardboardCreateOrder.php` и `ordersCardboardCopyOrder.php`, где объект `$flags` проверяет права доступа.
  * Подключается в `index.php` для инициализации безопасности перед маршрутизацией.

***

### 📑 Роль в АдминПанели

Файл `security.php` выполняет следующие функции в контексте АдминПанели:

* **Инициализация безопасности**: Подключает класс `CSRF` для защиты форм и AJAX-запросов от CSRF-атак.
* **Контроль авторизации**: Проверяет наличие авторизованного пользователя в сессии, обеспечивая доступ к защищенным модулям только для зарегистрированных пользователей.
* **Управление правами доступа**: Загружает флаги пользователя из базы данных и создает объект `UserFlags` для проверки разрешений в модулях приложения.
* **Интеграция с базой данных**: Извлекает данные о флагах из таблицы `orders_users`, связывая их с текущим пользователем.
* **Подготовка к маршрутизации**: Выполняется в `index.php` перед подключением маршрутизатора (`router.php`), чтобы обеспечить безопасность всех последующих операций.

***

### ⚙️ Технические детали

* **Сессии**: Использует `$_SESSION['user']` для хранения данных авторизованного пользователя, предполагая, что они установлены в процессе авторизации (например, в `login.php`).
* **База данных**: Выполняет запрос к таблице `orders_users` с использованием PDO для безопасной работы с параметрами (`:id`).
* **Флаги**: Хранятся в JSON-формате в поле `flags_json`, что позволяет гибко управлять разрешениями через класс `UserFlags`.
* **Безопасность**:
  * Подключает `CSRF.php` для защиты от CSRF-атак.
  * Создает объект `$flags` только для авторизованных пользователей, предотвращая доступ к функционалу неавторизованными лицами.
* **Предположения**:
  * Переменная `$read` — это PDO-объект, определенный в другом файле (например, `config.php`).
  * Поле `flags_json` в таблице `orders_users` содержит корректную JSON-строку с массивом флагов.
