# CSRF

## 📄 Документация по файлу `csrf.php` (АдминПанель)

Файл `csrf.php`, расположенный в директории `content/security`, является частью веб-приложения **АдминПанель**. Он содержит класс `CSRF`, предназначенный для защиты от атак межсайтовой подделки запросов (Cross-Site Request Forgery, CSRF) путем генерации, проверки и интеграции CSRF-токенов в формы. Документация описывает структуру, функциональность и назначение файла в контексте административной панели.

***

### 🚀 Обзор

Файл `csrf.php` выполняет следующие задачи:

* Определяет класс `CSRF` для управления CSRF-токенами.
* Генерирует уникальные токены для защиты HTTP-запросов (особенно POST и AJAX).
* Проверяет валидность токенов, отправленных с запросами.
* Предоставляет методы для получения токена и автоматической вставки его в HTML-формы.
* Обеспечивает безопасность веб-приложения, предотвращая несанкционированные действия от имени авторизованного пользователя.

Класс используется в модулях АдминПанели, таких как `ordersCardboardCreateOrder.php` и `ordersCardboardCopyOrder.php`, для защиты форм и AJAX-запросов.

***

### 📋 Структура и функциональность

#### 1. **Класс `CSRF`**

```php
class CSRF
{
    private static $tokenKey = '_csrf_token';
}
```

* **Описание**:
  * **Свойство**:
    * `$tokenKey` (private static string): Ключ, используемый для хранения CSRF-токена в сессии (`_csrf_token`).
  * Класс использует статические методы, что позволяет вызывать их без создания экземпляра.
* **Назначение**: Предоставляет централизованную функциональность для работы с CSRF-токенами, обеспечивая их хранение и управление через сессии.

***

#### 2. **Методы класса**

**2.1. `generateToken(): string`**

```php
public static function generateToken(): string
{
    if (!isset($_SESSION)) {
        session_start();
    }

    if (empty($_SESSION[self::$tokenKey])) {
        $_SESSION[self::$tokenKey] = bin2hex(random_bytes(32));
    }

    return $_SESSION[self::$tokenKey]; // Возвращаем токен
}
```

* **Описание**:
  * Генерирует новый CSRF-токен, если он еще не существует в сессии.
  * Проверяет, запущена ли сессия, и при необходимости вызывает `session_start()`.
  * Если токен отсутствует в `$_SESSION['_csrf_token']`, создает новый с помощью `bin2hex(random_bytes(32))`, генерируя 64-символьную шестнадцатеричную строку.
  * Сохраняет токен в сессии и возвращает его.
* **Возвращает**: `string` — CSRF-токен.
* **Назначение**: Создает уникальный токен для защиты запросов, связывая его с сессией пользователя.

***

**2.2. `validateToken(string $token): bool`**

```php
public static function validateToken(string $token): bool
{
    if (!isset($_SESSION)) {
        session_start();
    }

    return isset($_SESSION[self::$tokenKey]) && hash_equals($_SESSION[self::$tokenKey], $token);
}
```

* **Описание**:
  * Проверяет валидность переданного CSRF-токена `$token`.
  * Проверяет, запущена ли сессия, и при необходимости вызывает `session_start()`.
  * Сравнивает токен из сессии (`$_SESSION['_csrf_token']`) с переданным токеном, используя `hash_equals` для защиты от атак по времени.
  * Возвращает `true`, если токены совпадают, и `false`, если токен отсутствует или не совпадает.
* **Параметры**:
  * `$token` (string): CSRF-токен, переданный с запросом.
* **Возвращает**: `bool` — `true`, если токен валиден, `false` — если нет.
* **Назначение**: Используется для проверки токенов в POST-запросах или AJAX-запросах, чтобы убедиться, что запрос отправлен от легитимного пользователя.

***

**2.3. `getToken(): string`**

```php
public static function getToken(): string
{
    return self::generateToken();
}
```

* **Описание**:
  * Возвращает текущий CSRF-токен, вызывая метод `generateToken()`.
  * Если токен уже существует в сессии, возвращает его; иначе генерирует новый.
* **Возвращает**: `string` — CSRF-токен.
* **Назначение**: Упрощает получение токена для использования в формах или JavaScript-коде.

***

**2.4. `getTokenInput(): string`**

```php
public static function getTokenInput(): string
{
    $token = self::getToken();
    return sprintf('<input type="hidden" name="_csrf" value="%s">', htmlspecialchars($token, ENT_QUOTES, 'UTF-8'));
}
```

* **Описание**:
  * Генерирует HTML-код для скрытого поля ввода, содержащего CSRF-токен.
  * Получает токен через `getToken()`.
  * Экранирует токен с помощью `htmlspecialchars` для защиты от XSS-атак, используя кодировку UTF-8 и экранирование кавычек (`ENT_QUOTES`).
  * Формирует строку `<input type="hidden" name="_csrf" value="...">` с использованием `sprintf`.
* **Возвращает**: `string` — HTML-код скрытого поля с CSRF-токеном.
* **Назначение**: Упрощает интеграцию CSRF-токена в HTML-формы, автоматически добавляя его как скрытое поле.

### 🔗 Зависимости

Файл имеет следующие зависимости:

* **PHP**: Требуется версия PHP с поддержкой `session_start()`, `random_bytes`, `bin2hex`, `hash_equals` и `htmlspecialchars`.
* **Сессии**: Использует PHP-сессии для хранения CSRF-токена (`$_SESSION['_csrf_token']`).
* **Модули АдминПанели**: Используется в других файлах, таких как `ordersCardboardCreateOrder.php` и `ordersCardboardCopyOrder.php`, для генерации и проверки токенов в формах и AJAX-запросах.
* **Предполагаемые файлы**:
  * `content/function.php`: Вероятно, включает определение класса `CSRF` или другие вспомогательные функции.
  * `index.php`: Инициализирует сессии, необходимые для работы класса.

***

### 📑 Роль в АдминПанели

Файл `csrf.php` выполняет следующие функции в контексте АдминПанели:

* **Защита от CSRF-атак**: Генерирует и проверяет токены для всех POST-форм и AJAX-запросов, предотвращая выполнение несанкционированных действий от имени пользователя.
* **Интеграция с формами**: Предоставляет удобный метод `getTokenInput()` для автоматического добавления CSRF-токена в HTML-формы, как в `ordersCardboardCreateOrder.php`.
* **Безопасность AJAX-запросов**: Используется в JavaScript-коде для передачи токена с AJAX-запросами, обеспечивая их защиту (например, в `ordersCardboardCopyOrder.php`).
* **Централизованное управление**: Обеспечивает единый механизм управления CSRF-токенами, упрощая их использование во всех модулях приложения.
* **Поддержка сессий**: Связывает токены с сессией пользователя, гарантируя, что только легитимные запросы проходят проверку.

***

### ⚙️ Технические детали

* **Сессии**: Требует активной сессии для хранения и проверки токена. Автоматически запускает сессию, если она не инициализирована.
* **Генерация токена**: Использует криптографически безопасную функцию `random_bytes(32)` для создания 64-символьного токена в шестнадцатеричном формате.
* **Проверка токена**: Применяет `hash_equals` для безопасного сравнения строк, защищая от атак по времени.
* **Экранирование**: Использует `htmlspecialchars` для защиты токена от XSS-атак при вставке в HTML.
* **Статические методы**: Класс полностью статический, что позволяет вызывать методы без создания экземпляра (`CSRF::getToken()`).
