# flag

## 📄 Документация по файлу `flag.php` (АдминПанель)

Файл `flag.php`, расположенный в директории `content/security`, является частью веб-приложения **АдминПанель**. Он содержит класс `UserFlags`, который предоставляет функциональность для управления флагами доступа пользователей. Флаги представляют собой набор разрешений, определяющих, какие действия или разделы приложения доступны пользователю. Документация описывает структуру, функциональность и назначение файла в контексте административной панели.

***

### 🚀 Обзор

Файл `flag.php` выполняет следующие задачи:

* Определяет класс `UserFlags` для работы с флагами доступа пользователей.
* Хранит флаги в виде массива, инициализируемого из JSON-строки.
* Предоставляет методы для проверки наличия флагов, добавления, удаления, получения и установки флагов.
* Поддерживает специальный флаг `GLOBALADMIN`, предоставляющий полный доступ.
* Используется для контроля доступа к различным модулям АдминПанели, таким как создание заказов (`ordersCardboardCreateOrder.php`, `ordersCardboardCopyOrder.php`).

Класс является частью системы безопасности приложения, обеспечивая гибкое управление правами пользователей.

***

### 📋 Структура и функциональность

#### 1. **Класс `UserFlags`**

```php
class UserFlags
{
    private array $flags;

    public function __construct(string $flags)
    {
        // Декодируем JSON в массив
        $this->flags = json_decode($flags, true) ?? [];
    }
}
```

* **Описание**:
  * **Свойство**:
    * `$flags` (private array): Массив, содержащий список флагов пользователя, инициализируется из JSON-строки.
  * **Конструктор**:
    * Принимает строку `$flags` в формате JSON, содержащую массив флагов.
    * Декодирует JSON в массив с помощью `json_decode($flags, true)`.
    * Если декодирование не удалось (например, строка некорректна), устанавливает пустой массив (`[]`).
* **Назначение**: Инициализирует объект `UserFlags` с набором флагов, полученных из внешнего источника (например, базы данных или сессии).

***

#### 2. **Методы класса**

**2.1. `hasFlag(string $flag): bool`**

```php
public function hasFlag(string $flag): bool
{
    return in_array($flag, $this->flags);
}
```

* **Описание**:
  * Проверяет, есть ли указанный флаг `$flag` в массиве `$flags`.
  * Использует `in_array` для поиска флага.
* **Параметры**:
  * `$flag` (string): Название флага для проверки (например, `ORDERS_CARDBOARD_CREATEORDER`).
* **Возвращает**: `bool` — `true`, если флаг присутствует, `false` — если отсутствует.
* **Назначение**: Позволяет проверить, имеет ли пользователь конкретное разрешение.

***

**2.2. `hasAnyFlag(array $flags): bool`**

```php
public function hasAnyFlag(array $flags): bool
{
    if ($this->hasFlag('GLOBALADMIN')) {
        return true;
    }
    
    // Проверяем наличие хотя бы одного флага из списка
    foreach ($flags as $flag) {
        if ($this->hasFlag($flag)) {
            return true;
        }
    }
    return false;
}
```

* **Описание**:
  * Проверяет, имеет ли пользователь хотя бы один из флагов, указанных в массиве `$flags`.
  * Если пользователь имеет флаг `GLOBALADMIN`, возвращает `true` (полный доступ).
  * Иначе итерируется по массиву `$flags`, вызывая `hasFlag` для каждого флага.
  * Если ни один флаг не найден, возвращает `false`.
  * Содержит закомментированный HTML-код (вероятно, для отображения ошибки 403), который в текущей версии не используется.
* **Параметры**:
  * `$flags` (array): Массив строк, содержащих названия флагов для проверки.
* **Возвращает**: `bool` — `true`, если найден хотя бы один флаг или есть `GLOBALADMIN`, `false` — если флаги отсутствуют.
* **Назначение**: Используется для проверки доступа к модулям, требующим одного из нескольких разрешений (например, в `ordersCardboardCreateOrder.php`).

***

**2.3. `addFlag(string $flag): void`**

```php
public function addFlag(string $flag): void
{
    if (!$this->hasFlag($flag)) {
        $this->flags[] = $flag;
    }
}
```

* **Описание**:
  * Добавляет новый флаг `$flag` в массив `$flags`, если он еще не присутствует.
  * Проверяет наличие флага с помощью `hasFlag` перед добавлением.
* **Параметры**:
  * `$flag` (string): Название флага для добавления.
* **Возвращает**: Ничего (`void`).
* **Назначение**: Позволяет расширить права пользователя, добавляя новое разрешение.

***

**2.4. `removeFlag(string $flag): void`**

```php
public function removeFlag(string $flag): void
{
    $this->flags = array_filter($this->flags, fn($item) => $item !== $flag);
    $this->flags = array_values($this->flags); // Переиндексация массива
}
```

* **Описание**:
  * Удаляет указанный флаг `$flag` из массива `$flags`.
  * Использует `array_filter` с лямбда-функцией для исключения флага.
  * Переиндексирует массив с помощью `array_values` для поддержания непрерывных индексов.
* **Параметры**:
  * `$flag` (string): Название флага для удаления.
* **Возвращает**: Ничего (`void`).
* **Назначение**: Позволяет отозвать разрешение у пользователя.

***

* **Возвращает**: `string` — JSON-представление флагов.
