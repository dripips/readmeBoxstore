# ordersCardboardCopyOrder

## 📄 Документация по файлу `ordersCardboardCopyOrder.php` (АдминПанель)

Файл `ordersCardboardCopyOrder.php` является модулем веб-приложения **АдминПанель**, расположенным в директории `content/app/orders/cardboard`. Он отвечает за копирование существующего заказа на картонные коробки, позволяя пользователю найти заказ по номеру, просмотреть его детали (товары, информацию о клиенте и доставке) и перенести данные в форму создания нового заказа. Файл сочетает серверную логику на PHP с клиентским интерфейсом, использующим HTML, CSS, JavaScript, Alpine.js, Bootstrap и SweetAlert2. Документация описывает структуру, функциональность и назначение файла в контексте административной панели.

***

### 🚀 Обзор

Файл `ordersCardboardCopyOrder.php` выполняет следующие задачи:

* Проверяет права доступа пользователя через флаг `ORDERS_CARDBOARD_CREATEORDER`.
* Отображает интерфейс для ввода номера заказа и поиска его деталей.
* Получает данные о заказе (товары, клиент, доставка) через AJAX-запрос к серверу.
* Отображает информацию о заказе, клиенте (физическое/юридическое лицо) и доставке в удобном формате.
* Позволяет скопировать данные заказа в локальное хранилище и перенаправить пользователя на страницу создания нового заказа (`ordersCardboardCreateOrder.php`).
* Обеспечивает защиту от CSRF-атак с помощью токена.

***

### 📋 Структура и функциональность

#### 1. **Проверка прав доступа**

```php
<?php if ($flags->hasAnyFlag(['ORDERS_CARDBOARD_CREATEORDER'])): ?>
```

* **Описание**:
  * Проверяет наличие флага `ORDERS_CARDBOARD_CREATEORDER` у пользователя с помощью объекта `$flags` и метода `hasAnyFlag`.
  * Если флаг отсутствует, содержимое файла не отображается, ограничивая доступ к функционалу.
* **Назначение**: Обеспечивает контроль доступа, позволяя только авторизованным пользователям с соответствующими правами копировать заказы.

***

#### 2. **Клиентский интерфейс**

```html
<div 
    x-data="orderCopyHandler('<?=$path?>', '<?=CSRF::generateToken()?>')"
    x-init="init()"
    @keydown.enter="$event.target.id === 'orderNumber' && fetchOrder()"
    class="space-y-6"
>
    <!-- Breadcrumbs -->
    <ul class="flex space-x-2 rtl:space-x-reverse text-sm"> ... </ul>

    <h2 class="text-2xl font-semibold">Копирование заказа</h2>

    <!-- Search Panel -->
    <div class="panel"> ... </div>

    <!-- Order Info Container -->
    <template x-if="orderData"> ... </template>

    <!-- Not Found Message -->
    <template x-if="orderNotFound"> ... </template>
</div>
```

* **Описание**:
  * **Компонент Alpine.js**: Использует компонент `orderCopyHandler`, передавая путь приложения (`$path`) и CSRF-токен (`CSRF::generateToken()`).
  * **Хлебные крошки**: Навигационная панель с ссылкой на раздел "Заказы" и текущей страницей "Копирование заказа".
  * **Поиск заказа**:
    * Поле ввода (`orderNumber`) для номера заказа и кнопка "Найти", активируемая при непустом значении поля.
    * Поддерживает поиск по нажатию клавиши Enter в поле ввода.
  * **Информация о заказе** (отображается при наличии `orderData`):
    * **Таблица товаров**: Показывает товары заказа (название, количество, закупочная цена, цена, стоимость).
    * **Информация о клиенте**: Отображает ФИО, телефон, email и комментарий клиента (в режиме только чтение).
    * **Юридическая информация** (для юридических лиц): Показывает ИНН, адрес и наименование компании.
    * **Информация о доставке**: Указывает тип доставки и адрес, включая код ПВЗ для доставки через СДЭК.
    * Кнопка "Продолжить" для копирования заказа.
  * **Сообщение об ошибке**: Если заказ не найден (`orderNotFound`), отображается панель с текстом "Заказ не найден".
  * **Стилизация**: Использует Bootstrap для оформления (`panel`, `btn`, `form-input`, `table`, `grid`).
* **Назначение**: Обеспечивает интерактивный интерфейс для поиска заказа, просмотра его деталей и инициации копирования.

***

#### 3. **JavaScript-логика (Alpine.js)**

```javascript
<script>
document.addEventListener('alpine:init', () => {
    Alpine.data('orderCopyHandler', (path, csrfToken) => ({
        orderNumber: '',
        orderData: null,
        clientData: {},
        legalData: {},
        deliveryData: {},
        itemsO: [],
        orderNotFound: false,

        init() { ... },

        async fetchOrder() { ... },

        resetData() { ... },

        copyOrder() { ... }
    }));
});
</script>
```

* **Описание**:
  * **Компонент `orderCopyHandler`**:
    * **Данные**:
      * `orderNumber`: Номер заказа, введенный пользователем.
      * `orderData`: Данные заказа, полученные от сервера.
      * `clientData`: Информация о клиенте (ФИО, телефон, email).
      * `legalData`: Юридическая информация (ИНН, адрес, наименование).
      * `deliveryData`: Данные о доставке (тип, адрес, код ПВЗ).
      * `itemsO`: Список товаров для копирования в новый заказ.
      * `orderNotFound`: Флаг, указывающий, что заказ не найден.
    * **Методы**:
      * `init()`: Пустая функция инициализации (может быть расширена).
      * `fetchOrder()`: Отправляет AJAX-запрос к `assets/app/php/orders/cardboard/copyOrder.php` с номером заказа и CSRF-токеном, обрабатывает ответ, заполняя `orderData`, `clientData`, `legalData`, `deliveryData`, `itemsO` или устанавливая `orderNotFound`.
      * `resetData()`: Сбрасывает все данные компонента при ошибке или новом поиске.
      * `copyOrder()`: Сохраняет данные заказа, клиента, юридической информации и доставки в `localStorage` и перенаправляет на страницу создания заказа (`ordersCardboardCreateOrder.php`) с параметром `active=copy`.
  * **Библиотеки**:
    * **Alpine.js**: Управляет состоянием и интерактивностью.
    * **SweetAlert2 (Swal)**: Отображает модальные окна для уведомлений и ошибок.
    * **Fetch API**: Используется для отправки AJAX-запросов.
* **Назначение**: Обеспечивает динамическую загрузку данных заказа, их отображение и копирование в форму создания нового заказа.

### 🔗 Зависимости

Файл зависит от следующих компонентов:

* **Серверные объекты**:
  * `$flags`: Объект для проверки прав доступа (`hasAnyFlag`).
  * `$path`: Переменная, содержащая базовый путь приложения (из `config.php`).
  * `CSRF`: Класс для генерации и проверки CSRF-токенов (вероятно, из `content/function.php`).
* **Файлы**:
  * `assets/app/php/orders/cardboard/copyOrder.php`: Скрипт для получения данных заказа по номеру.
  * `content/app/orders/cardboard/ordersCardboardCreateOrder.php`: Страница создания заказа, куда перенаправляется пользователь после копирования.
* **Библиотеки**:
  * **Bootstrap**: Для стилизации интерфейса (`panel`, `btn`, `form-input`, `table`, `grid`).
  * **Alpine.js**: Для управления состоянием и интерактивностью.
  * **SweetAlert2**: Для отображения уведомлений и ошибок.
  * **Fetch API**: Для выполнения AJAX-запросов.

### 📑 Роль в АдминПанели

Файл `ordersCardboardCopyOrder.php` выполняет следующие функции в контексте АдминПанели:

* **Копирование заказов**: Позволяет пользователю найти существующий заказ по номеру и использовать его данные для создания нового заказа.
* **Интеграция с CRM**: Получает данные заказа через API (предположительно RetailCRM) с помощью серверного скрипта `copyOrder.php`.
* **Удобство интерфейса**: Отображает товары, информацию о клиенте и доставке в удобном формате, минимизируя необходимость повторного ввода данных.
* **Безопасность**: Использует CSRF-токены для защиты AJAX-запросов и проверяет права доступа через флаги.
* **Интеграция с созданием заказа**: Переносит данные в `localStorage` и перенаправляет на страницу `ordersCardboardCreateOrder.php` для завершения создания заказа.

* **Безопасность**: Применяет CSRF-токены для защиты AJAX-запросов.
