# АдминПанель (new-manage)

## 📊 Полномасштабное описание группы проектов АдминПанель

**АдминПанель** — это комплексное веб-приложение, разработанное для управления складскими операциями, заказами, производством, доставкой, интеграцией с маркетплейсами и администрирования. Оно построено на PHP с использованием HTML, CSS, JavaScript и различных библиотек для интерфейса и функциональности. В данном описании я опишу структуру проекта, расположение файлов, используемые технологии и взаимодействие компонентов, основываясь на предоставленных файлах (`index.php`, `router.php`) и указанных деталях.

***

### 🚀 Обзор проекта

**АдминПанель** — это административная система, которая поддерживает широкий спектр функций, включая:

* Управление складом (картон, коробки, пластик).
* Обработку заказов (создание, копирование, редактирование, учет).
* Организацию доставки (интеграция с СДЭК).
* Управление производством (статистика персонала, генерация чертежей, логи упаковки).
* Интеграцию с маркетплейсами (Ozon, Wildberries, Яндекс).
* Администрирование (управление пользователями, промокодами, параметрами калькуляции).
* Генерацию чертежей для коробок различных типов (FEFCO и негенеративные).
* Тестирование и экспериментальные модули.

Приложение ориентировано на авторизованных пользователей, с разделением доступа для разных ролей (администраторы, персонал, мейкеры). Оно использует серверную логику на PHP и клиентские технологии для интерактивного интерфейса.

### 🛠️ Используемые технологии

#### 1. **Серверная часть**

* **PHP**: Основной язык серверной логики, используемый для маршрутизации (`index.php`, `router.php`), обработки сессий, подключения модулей и выполнения бизнес-логики.
* **Сессии PHP**: Для управления авторизацией пользователей (`$_SESSION['user']`).
* **cURL**: Используется в трейте `RequestHandler` для отправки HTTP-запросов к API CRM (через `RCRM`).

#### 2. **Клиентская часть**

* **HTML**: Основа интерфейса страниц (в шаблонах `header.php`, `footer.php` и модулях `content/app`).
* **CSS**: Стили для оформления интерфейса, вероятно, хранятся в `assets/app/css/`.
* **JavaScript**:
  * **AJAX**: Для асинхронных запросов к серверу, отправляемых на скрипты в `assets/app/php/`.
  * **Alpine.js**: Легковесный фреймворк для добавления интерактивности (например, для выпадающих меню, модальных окон).
  * **Chart.js**: Для визуализации данных (например, статистика персонала, метрики платформы).
* **Bootstrap**: CSS-фреймворк для адаптивного дизайна и компонентов интерфейса (кнопки, таблицы, формы).
* **jQuery** (предположительно): Может использоваться для упрощения AJAX-запросов и работы с DOM.

#### 3. **Внешние интеграции**

* **CRM**: Интеграция через `RCRM` для управления заказами, клиентами и расходами.
* **Маркетплейсы**: Модули для Ozon, Wildberries, Яндекс (FBO, загрузка/редактирование товаров).
* **СДЭК**: Модули доставки для картона и пластика.
* **Redis**: Кэширование и интеграция с Airtable, Ozon, СДЭК, CRM.
* **Airtable**: Хранение данных (например, для тестовых модулей или метрик).

### 🔗 Взаимодействие компонентов

#### 1. **Точка входа (`index.php`)**

* Инициализирует окружение, сессии и подключает конфигурацию.
* Проверяет авторизацию:
  * Неавторизованные пользователи направляются на `login.php` или `register.php`.
  * Авторизованные пользователи получают доступ к интерфейсу через `header.php`, `router.php` и `footer.php`.

#### 2. **Маршрутизация (`router.php`)**

* Проверяет `$_SESSION['user']` и перенаправляет неавторизованных на `/`.
* Использует `$_GET['do']` для выбора модуля из `content/app`.
* Подключает `dashboard.php` по умолчанию, если маршрут не указан.

#### 3. **Серверная логика (`content/app`)**

* Модули в `content/app` обрабатывают бизнес-логику (например, управление складом, заказами, производством).
* Каждый модуль представляет отдельную страницу или функциональность, отображаемую в интерфейсе.
* Модули могут использовать функции из `content/function.php` или взаимодействовать с базой данных.

#### 4. **Клиентская часть**

* **Шаблоны** (`header.php`, `footer.php`): Формируют общий макет страниц (навигация, футер).
* **AJAX-запросы**: Отправляются из JavaScript (в `assets/app/js`) на серверные скрипты в `assets/app/php` для асинхронного обновления данных (например, загрузка статистики, обновление заказов).
* **Интерактивность**:
  * **Alpine.js**: Управляет динамическими элементами (например, раскрывающиеся списки, формы).
  * **Chart.js**: Отображает графики (например, метрики платформы, статистика персонала).
  * **Bootstrap**: Обеспечивает адаптивный дизайн и готовые компоненты (таблицы, модальные окна).

#### 5. **Внешние запросы**

* Модули в `content/app/marketplaces` и `content/app/delivery` отправляют запросы к API маркетплейсов и СДЭК через `RCRM` или аналогичные классы.
* Скрипты в `assets/app/php` обрабатывают AJAX-запросы, взаимодействуя с базой данных или API.

### 📑 Роль в АдминПанели

**АдминПанель** — это многофункциональная система для управления бизнес-процессами, связанными с производством и продажей упаковки (картон, коробки, пластик). Ее ключевые роли:

* **Управление складом**: Учет остатков, расхода, поставок и цен.
* **Обработка заказов**: Создание, копирование, редактирование заказов и их доставки.
* **Производство**: Координация персонала, мейкеров, генерация чертежей, логи упаковки.
* **Интеграция с маркетплейсами**: Загрузка и редактирование товаров на Ozon, Wildberries, Яндекс.
* **Доставка**: Организация доставки через СДЭК (до двери или пункта выдачи).
* **Администрирование**: Управление пользователями, промокодами, параметрами калькуляции, кэшированием через Redis.
* **Тестирование**: Поддержка экспериментальных модулей для разработчиков.

Файлы `index.php` и `router.php` обеспечивают базовую структуру приложения, направляя запросы к соответствующим модулям в `content/app`.

### ⚙️ Технические детали

* **Сессии**: Используются для контроля авторизации (`$_SESSION['user']`).
* **Маршрутизация**: Основана на `$_GET['do']`, с подключением PHP-файлов через `include`.
* **Файловая структура**: Модульная, с разделением по функциональным категориям в `content/app`.
* **Клиент-серверное взаимодействие**: AJAX-запросы из `assets/app/js` обрабатываются скриптами в `assets/app/php`.
* **Интерфейс**: Адаптивный (Bootstrap), интерактивный (Alpine.js), с визуализацией данных (Chart.js).
* **Интеграции**: CRM (`RCRM`), маркетплейсы, СДЭК, Redis, Airtable, NocoDb.
