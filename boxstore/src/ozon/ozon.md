# Ozon

## 🛒 Документация по классу Ozon

Добро пожаловать в документацию по классу `Ozon`! 🎉 Этот PHP-класс, расположенный в пространстве имен `Ozon`, предназначен для взаимодействия с API Ozon, предоставляя методы для работы с отправлениями (FBS и FBO), а также для генерации и сохранения штрихкодов. Класс использует объект `Request` для отправки HTTP-запросов и поддерживает авторизацию через `Client-Id` и `Api-Key`. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `Ozon` разработан для упрощения работы с API Ozon, предоставляя следующие возможности:

* Получение списка и информации об отправлениях FBS и FBO 📋
* Создание задач для генерации штрихкодов и их сохранение в виде PDF-файлов 🏷️
* Авторизация через `Client-Id` и `Api-Key` для безопасного доступа 🔒

Класс интегрируется с API Ozon через базовый URL и использует объект `Request` для выполнения HTTP-запросов. Он идеально подходит для автоматизации процессов управления заказами и логистики на платформе Ozon.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `Ozon`, выполните следующие шаги:

1.  **Подключите классы**: Убедитесь, что файлы классов `Ozon` и `Request` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Ozon.php';
    require_once 'path/to/Request.php';
    ```
2. **Получите учетные данные API**:
   * Зарегистрируйтесь в Ozon Seller и получите `Client-Id` и `Api-Key` для авторизации.
   * Определите базовый URL API (например, `https://api-seller.ozon.ru`).
3.  **Создайте экземпляр класса**: Передайте базовый URL, API-ключ и Client-Id в конструктор.

    ```php
    use Ozon\Ozon;
    $ozon = new Ozon('https://api-seller.ozon.ru', 'your_api_key', 'your_client_id');
    ```
4. **Используйте методы**: Вызывайте методы для работы с отправлениями или штрихкодами (подробности ниже).

### 📋 Методы и использование

Ниже приведен полный список методов класса `Ozon`, их назначение, параметры и примеры использования.

#### 1. `__construct(string $apiBaseUrl, string $apiKey, string $clientId)` 🛠️

Инициализирует класс, устанавливая базовый URL API и объект `Request` с авторизацией.

* **Параметры**:
  * `$apiBaseUrl` (string): Базовый URL API Ozon (например, `https://api-seller.ozon.ru`).
  * `$apiKey` (string): API-ключ для авторизации.
  * `$clientId` (string): Client-Id для авторизации.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $ozon = new Ozon('https://api-seller.ozon.ru', 'your_api_key', 'your_client_id');
    ```

***

#### 2. `getPostingsFbs(array $body)` 📋

Получает список отправлений FBS (Fulfillment by Seller) с фильтрацией.

* **Параметры**:
  * `$body` (array): Параметры фильтрации (например, `filter`, `limit`, `offset`).
* **Возвращает**: Массив с данными отправлений.
* **Исключения**: `Exception` при ошибке API или cURL.
*   **Пример**:

    ```php
    $body = [
        'filter' => [
            'status' => 'awaiting_packaging',
            'since' => '2025-01-01T00:00:00Z',
            'to' => '2025-12-31T23:59:59Z'
        ],
        'limit' => 100,
        'offset' => 0
    ];
    try {
        $postings = $ozon->getPostingsFbs($body);
        print_r($postings);
        // Вывод: Список отправлений FBS
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 3. `getPostingFbs(array $body)` 🔍

Получает информацию о конкретном отправлении FBS.

* **Параметры**:
  * `$body` (array): Данные запроса (например, `posting_number`).
* **Возвращает**: Массив с данными отправления.
*   **Пример**:

    ```php

        'posting_number' => '123456-789-0'
    ];
    try {
        $posting = $ozon->getPostingFbs($body);

    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 6. `getBarcode($postingNumber)` 🏷️

Генерирует и сохраняет PDF-штрихкод для отправления, возвращая информацию о файле.

* **Параметры**:
  * `$postingNumber` (string): Номер отправления.
* **Возвращает**: Массив с информацией о файле (или `false` при ошибке).
*   **Пример**:

    ```php
    try {
        $barcode = $ozon->getBarcode('123456-789-0');
        print_r($barcode);
        // Вывод: [
        //     'result' => 'access',
        //     'ozon_url' => '...',
        //     'file_path' => '...',
        //     'file_url' => 'https://cloud.muul.ru/ozon-barcodes/pdf/123456-789-0.pdf'
        // ]
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 7. `createBarcodeTask($postingNumber)` 📝

Создает задачу для генерации штрихкода.

* **Параметры**:
  * `$postingNumber` (string): Номер отправления.
* **Возвращает**: ID задачи (`task_id`) или `null` при ошибке.
*   **Пример**:

    ```php
    $taskId = $ozon->createBarcodeTask('123456-789-0');
    echo $taskId ?: 'Ошибка создания задачи';
    // Вывод: ID задачи (например, 'task_123')
    ```

***

#### 8. `waitForTaskCompletion($taskId)` ⏳

Ожидает завершения задачи генерации штрихкода и возвращает URL файла.

* **Параметры**:
  * `$taskId` (string): ID задачи.
* **Возвращает**: URL файла или `null` при ошибке или превышении попыток.
*   **Пример**:

    ```php
    $fileUrl = $ozon->waitForTaskCompletion('task_123');
    echo $fileUrl ?: 'Файл не готов';
    // Вывод: URL файла (например, 'https://ozon.ru/file.pdf')
    ```

***

#### 9. `getBarcodeTaskStatus($taskId)` 🔍

(Приватный метод) Получает статус задачи генерации штрихкода.

* **Параметры**:
  * `$taskId` (string): ID задачи.
* **Возвращает**: Массив с информацией о задаче или `null` при ошибке.
* **Примечание**: Вызывается автоматически в `waitForTaskCompletion`.

***

#### 10. `saveBarcodeFile($postingNumber, $fileUrl)` 💾

Сохраняет PDF-штрихкод на сервере и возвращает информацию о файле.

* **Параметры**:
  * `$postingNumber` (string): Номер отправления.
  * `$fileUrl` (string): URL PDF-файла.
* **Возвращает**: Массив с информацией о файле (или `false` при ошибке).
*   **Пример**:

    ```php
    $result = $ozon->saveBarcodeFile('123456-789-0', 'https://ozon.ru/file.pdf');
    print_r($result);
    // Вывод: Информация о сохраненном файле
    ```

***

#### 11. `saveFile($path, $link)` 💾

(Приватный метод) Сохраняет файл по URL в указанный путь.

* **Параметры**:
  * `$path` (string): Путь для сохранения файла.
  * `$link` (string): URL файла.
* **Исключения**: `Exception` при ошибке записи или cURL.
* **Примечание**: Вызывается автоматически в `saveBarcodeFile`.

### ⚠️ Лучшие практики

*   **Обработка ошибок**: Класс `Request` и метод `saveFile` могут выбрасывать исключения. Оборачивайте вызовы методов в try-catch.

    ```php
    try {
        $postings = $ozon->getPostingsFbs([]);
        print_r($postings);
    } catch (Exception $e) {
        error_log('Ошибка: ' . $e->getMessage());
        echo 'Произошла ошибка';
    }
    ```
* **Безопасность учетных данных**: Храните `$apiKey` и `$clientId` в безопасном месте (например, в конфигурационном файле или переменных окружения).
* **Проверка пути сохранения**: Убедитесь, что директория `$_SERVER['DOCUMENT_ROOT'] . '/ozon-barcodes/pdf/'` существует и доступна для записи перед вызовом `getBarcode`.
* **Ограничения API**: Учитывайте лимиты API Ozon (например, максимум 100 записей в `limit` для `getPostingsFbs`) и проверяйте структуру `$body`.
* **Ожидание задач**: Метод `waitForTaskCompletion` имеет максимум 30 попыток с интервалом 2 секунды. При необходимости настройте `$maxAttempts` или интервал для конкретных сценариев.
* **Логирование**: Внедрите логирование запросов, ответов и операций с файлами для упрощения отладки и мониторинга.
* **Кэширование**: Если данные отправлений редко меняются, рассмотрите кэширование результатов для оптимизации производительности.

***

### 🐛 Устранение неполадок

* **Ошибка авторизации (401)**: Если запросы возвращают ошибку 401, проверьте:
  * Правильность `$apiKey` и `$clientId`.
  * Срок действия учетных данных.
* **Ошибка API (400, 404, 422)**: Проверьте:
  * Корректность структуры `$body` (наличие обязательных полей, правильные типы данных).
  * Существование `$postingNumber` в системе Ozon.
  * Соответствие параметров документации API Ozon.
* **Проблемы с сохранением PDF**:
  * Убедитесь, что директория `ozon-barcodes/pdf/` существует и имеет права на запись.
  * Проверьте доступность `$fileUrl` в `saveBarcodeFile`.
* **Ошибки cURL**: Если методы выбрасывают исключения cURL:
  * Проверьте доступность API (`$apiBaseUrl`).
  * Убедитесь, что расширение cURL включено в PHP.
  * Проверьте сетевые настройки (прокси, брандмауэр).
* **Задача штрихкода не завершается**: Если `waitForTaskCompletion` возвращает `null`:
  * Проверьте, успешно ли создана задача (`createBarcodeTask`).
  * Увеличьте `$maxAttempts` или интервал ожидания, если сервер Ozon отвечает медленно.
