# OzonCardboard

## 📦 Документация по классу OzonCardboard

Добро пожаловать в документацию по классу `OzonCardboard`! 🎉 Этот PHP-класс, расположенный в пространстве имен `Ozon`, наследуется от класса `Ozon` и предназначен для работы с API Ozon, специализируясь на управлении упаковкой заказов с картонными изделиями. Он предоставляет методы для отправки запросов на сборку заказов и формирования упаковок с учетом специфики магазина и типа коробок. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `OzonCardboard` расширяет функциональность родительского класса `Ozon`, добавляя логику для обработки заказов с картонными изделиями. Основные задачи класса:

* Отправка запросов на сборку заказов в системе Ozon 📋
* Формирование упаковок для отправлений с учетом типа коробок и магазина 📦
* Парсинг артикулов для извлечения характеристик товара (тип, картон, цвет, размеры, количество) 🔍
* Поддержка специфичных требований магазина BOXSTORE HAPPY и других магазинов 🏪

Класс использует объект `Request` для отправки HTTP-запросов и наследует авторизацию через `Client-Id` и `Api-Key` от родительского класса `Ozon`. Он оптимизирован для работы с картонными изделиями, учитывая их типы (427, 330, 201, 215) и количество коробок в упаковке.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `OzonCardboard`, выполните следующие шаги:

1.  **Подключите классы**: Убедитесь, что файлы классов `Ozon`, `OzonCardboard` и `Request` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Ozon.php';
    require_once 'path/to/OzonCardboard.php';
    require_once 'path/to/Request.php';
    ```
2. **Получите учетные данные API**:
   * Зарегистрируйтесь в Ozon Seller и получите `Client-Id` и `Api-Key` для авторизации.
   * Определите базовый URL API (например, `https://api-seller.ozon.ru`).
3.  **Создайте экземпляр класса**: Передайте базовый URL, API-ключ и Client-Id в конструктор.

    ```php
    use Ozon\OzonCardboard;
    $ozonCardboard = new OzonCardboard('https://api-seller.ozon.ru', 'your_api_key', 'your_client_id');
    ```
4. **Используйте методы**: Вызывайте методы для сборки заказов или формирования упаковок (подробности ниже).

### 📋 Методы и использование

Класс `OzonCardboard` наследует все методы родительского класса `Ozon` (например, `getPostingsFbs`, `getPostingFbs`, `getBarcode`) и добавляет новые методы для работы с картонными изделиями. Ниже описаны специфичные методы класса.

#### 1. `__construct(string $apiBaseUrl, string $apiKey, string $clientId)` 🛠️

Инициализирует класс, вызывая конструктор родительского класса `Ozon` для настройки авторизации и объекта `Request`.

* **Параметры**:
  * `$apiBaseUrl` (string): Базовый URL API Ozon.
  * `$apiKey` (string): API-ключ для авторизации.
  * `$clientId` (string): Client-Id для авторизации.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $ozonCardboard = new OzonCardboard('https://api-seller.ozon.ru', 'your_api_key', 'your_client_id');
    ```

***

#### 2. `packaginOrder($posting_number)` 📋

Отправляет запрос на сборку заказа в системе Ozon, формируя упаковки для указанного отправления.

* **Параметры**:
  * `$posting_number` (string): Номер отправления Ozon.
* **Возвращает**: Массив с результатом запроса или ошибкой.
*   **Пример**:

    ```php
    try {
        $result = $ozonCardboard->packaginOrder('123456-789-0');
        print_r($result);
        // Вывод: Ответ API или ['success' => true, 'error_message' => '...']
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 3. `deshifrator($article)` 🔍

(Приватный метод) Парсит артикул товара для извлечения характеристик (тип, картон, цвет, размеры, количество, группа).

* **Параметры**:
  * `$article` (string): Артикул в формате `TYPE-CARDBOARD-COLOR1-COLOR2-LENGTH-WIDTH-HEIGHT-COUNT-GROUP`.
* **Возвращает**: Массив с ключами `type`, `cardboard`, `color`, `length`, `width`, `height`, `count`, `group`.
*   **Пример**:

    ```php
    $article = '427-CARDBOARD-WHITE-BLUE-600-400-100-10-GROUP1';
    $params = $this->deshifrator($article);
    print_r($params);
    // Вывод: [
    //     'type' => '427',
    //     'cardboard' => 'CARDBOARD',
    //     'color' => 'WHITE-BLUE',
    //     'length' => '600',
    //     'width' => '400',
    //     'height' => '100',
    //     'count' => '10',
    //     'group' => 'GROUP1'
    // ]
    ```

***

#### 4. `getPackages($posting_number)` 📦

(Приватный метод) Формирует массив упаковок для отправления на основе его продуктов и склада.

* **Параметры**:
  * `$posting_number` (string): Номер отправления Ozon.
* **Возвращает**: Массив с ключами `success` и `packages` (или `error_message` при ошибке).
* **Примечание**: Вызывается автоматически в `packaginOrder`.

***

#### 5. `splitForPackages($product, $warehouse)` 📏

(Приватный метод) Определяет логику формирования упаковок в зависимости от склада (`BOXSTORE HAPPY` или другие магазины).

* **Параметры**:
  * `$product` (array): Данные продукта из API Ozon.
  * `$warehouse` (string): Название склада.
* **Возвращает**: Массив с ключами `success` и `package` (или `error_message`).
* **Примечание**: Вызывается автоматически в `getPackages`.

***

#### 6. `packageBoxstoreHappy($product)` 📦

(Приватный метод) Формирует упаковки для магазина BOXSTORE HAPPY, разбивая каждый продукт на отдельные упаковки.

* **Параметры**:
  * `$product` (array): Данные продукта из API Ozon.
* **Возвращает**: Массив упаковок.
* **Примечание**: Вызывается автоматически в `splitForPackages`.

***

#### 7. `packageDefaultShops($product)` 📦

(Приватный метод) Формирует упаковки для остальных магазинов, используя логику для типов коробок (427, 330, 201, 215).

* **Параметры**:
  * `$product` (array): Данные продукта из API Ozon.
* **Возвращает**: Массив упаковок или пустой массив при ошибке.
* **Примечание**: Вызывается автоматически в `splitForPackages`.

***

#### 8. `split427($quantity, $countBoxes, $sku)` 📏

(Приватный метод) Разбивает позиции коробки типа 427 на упаковки.

* **Параметры**:
  * `$quantity` (int): Количество позиций.
  * `$countBoxes` (string): Количество коробок в одной позиции.
  * `$sku` (string): SKU продукта в Ozon.
* **Возвращает**: Массив с ключами `success` и `package` (или `error_message`).
* **Логика**:
  * Поддерживает `countBoxes` = 10 или 30.
  * Максимум 100 коробок в упаковке.
* **Примечание**: Вызывается автоматически в `packageDefaultShops`.

### ⚠️ Лучшие практики

*   **Обработка ошибок**: Класс `Request` и методы могут выбрасывать исключения. Оборачивайте вызовы в try-catch.

    ```php
    try {
        $result = $ozonCardboard->packaginOrder('123456-789-0');
        print_r($result);
    } catch (Exception $e) {
        error_log('Ошибка: ' . $e->getMessage());
        echo 'Произошла ошибка';
    }
    ```
* **Валидация артикулов**: Убедитесь, что артикулы соответствуют формату `TYPE-CARDBOARD-COLOR1-COLOR2-LENGTH-WIDTH-HEIGHT-COUNT-GROUP`, чтобы `deshifrator` работал корректно.
* **Проверка склада**: Метод `splitForPackages` зависит от названия склада (`BOXSTORE HAPPY РЦ`). Убедитесь, что значение `$warehouse` соответствует ожидаемому.
* **Ограничения коробок**: Методы `split*` поддерживают только определенные значения `countBoxes` (10, 30 для 427; 10 для 330, 201, 215). Проверяйте входные данные.
* **Логирование**: Внедрите логирование запросов, ответов и ошибок для упрощения отладки.
* **Наследование**: Используйте методы родительского класса `Ozon` (например, `getBarcode`) для дополнительных операций, таких как генерация штрихкодов.

### 🐛 Устранение неполадок

* **Ошибка API**: Если методы возвращают ошибки (400, 422), проверьте:
  * Корректность `$posting_number` и структуры `$body` в `packaginOrder`.
  * Соответствие параметров документации API Ozon.
* **Проблемы с артикулом**: Если `deshifrator` возвращает некорректные данные:
  * Убедитесь, что артикул содержит 9 частей, разделенных дефисами.
  * Проверьте, что `countBoxes` соответствует допустимым значениям.
* **Пустые упаковки**: Если `getPackages` или `splitForPackages` возвращают ошибку:
  * Проверьте, возвращает ли `getPostingFbs` продукты (`$ozonInfo['result']['products']`).
  * Убедитесь, что склад (`$warehouse`) распознан корректно.
* **Ошибки cURL**: Если методы выбрасывают исключения cURL:
  * Проверьте доступность API (`$apiBaseUrl`).
  * Убедитесь, что расширение cURL включено в PHP.
  * Проверьте сетевые настройки (прокси, брандмауэр).
* **Неподдерживаемый тип коробки**: Если `packageDefaultShops` возвращает пустой массив, проверьте, что `$params['type']` соответствует одному из типов (427, 330, 201, 215).
