# Nocodb

## 📊 Документация по классу Nocodb

Добро пожаловать в документацию по классу `Nocodb`! 🎉 Этот PHP-класс, расположенный в пространстве имен `Nocodb`, предназначен для взаимодействия с API NocoDB, предоставляя методы для работы с записями, фильтрацией данных и загрузкой файлов. Класс использует объект `Request` для отправки HTTP-запросов и включает встроенные справочники полей и операторов. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `Nocodb` разработан для упрощения работы с базой данных NocoDB, поддерживая следующие операции:

* Получение, создание, обновление и удаление записей 📋
* Фильтрация данных с использованием операторов, аналогичных Airtable 🔍
* Загрузка одиночных и множественных файлов в хранилище NocoDB 📤
* Предоставление справочников полей (например, цвета, статусы, картон) 🎨

Класс инициализируется с токеном и ID таблицы, использует авторизацию через `xc-token` и интегрируется с классом `Request` для выполнения запросов. Он также включает предопределенные справочники (`fields`) и маппинг операторов (`operatorsNoco`) для удобной работы с фильтрами.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `Nocodb`, выполните следующие шаги:

1.  **Подключите классы**: Убедитесь, что файлы классов `Nocodb` и `Request` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Nocodb.php';
    require_once 'path/to/Request.php';
    ```
2. **Получите учетные данные NocoDB**:
   * Зарегистрируйтесь в NocoDB и получите `xc-token` для авторизации.
   * Определите ID таблицы, с которой будете работать (например, из конфигурации проекта).
3.  **Создайте экземпляр класса**: Передайте конфигурацию (включая `xc-token` и ID таблицы) и имя таблицы.

    ```php
    use Nocodb\Nocodb;
    $config = [
        'xc-token' => 'your_xc_token',
        'table_name' => 'your_table_id'
    ];
    $nocodb = new Nocodb($config, 'table_name');
    ```
4. **Используйте методы**: Вызывайте методы для работы с записями, фильтрами или загрузкой файлов (подробности ниже).

***

### 📋 Методы и использование

Ниже приведен полный список методов класса `Nocodb`, их назначение, параметры и примеры использования.

#### 1. `__construct($config, $table_name)` 🛠️

Инициализирует класс, устанавливая токен, ID таблицы и объект `Request`.

* **Параметры**:
  * `$config` (array): Конфигурация с ключами `xc-token` (токен авторизации) и `$table_name` (ID таблицы).
  * `$table_name` (string): Имя ключа в конфигурации, соответствующее ID таблицы.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $config = [
        'xc-token' => 'your_xc_token',
        'orders' => 'table_id_123'
    ];
    $nocodb = new Nocodb($config, 'orders');
    ```

***

#### 2. `getFields()` 📋

Возвращает справочник полей, включая цвета, статусы заказов, типы картона и другие предопределенные значения.

* **Параметры**: Нет
* **Возвращает**: Массив с предопределенными значениями полей.
*   **Пример**:

    ```php
    $fields = $nocodb->getFields();
    print_r($fields['colors']);
    // Вывод: Массив цветов с их bg и border значениями
    ```

***

#### 3. `getRecords(array $body = [])` 📊

Получает список записей из таблицы с возможностью фильтрации, сортировки и пагинации.

* **Параметры**:
  * `$body` (array): Параметры запроса:
    * `fields` (string): Список полей для получения (через запятую).
    * `sort` (string): Порядок сортировки (например, `field1,-field2`).
    * `where` (string): Строка фильтров в формате NocoDB.
    * `offset` (int): Количество пропущенных записей.
    * `limit` (int): Максимальное количество возвращаемых записей.
    * `viewId` (string): ID представления.
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`).
*   **Пример**:

    ```php
    $body = [
        'fields' => 'Id,Name,Status',
        'where' => '(Status,eq,Active)',
        'limit' => 10,
        'offset' => 0
    ];
    $records = $nocodb->getRecords($body);
    print_r($records);
    // Вывод: Список записей
    ```

***

#### 4. `getRecord(string $recordId, array $body = [])` 🔍

Получает информацию о записи по её ID.

* **Параметры**:
  * `$recordId` (string): ID записи.
  * `$body` (array): Параметры запроса (например, `fields` для выбора полей).
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`).
*   **Пример**:

    ```php
    $record = $nocodb->getRecord('rec_123', ['fields' => 'Id,Name']);
    print_r($record);
    // Вывод: Данные записи
    ```

***

#### 5. `createRecord(array $body)` ➕

Создает одну или несколько записей в таблице.

* **Параметры**:
  * `$body` (array): Данные для создания записи(ей). Формат:
    * Для одной записи: `['Field1' => 'Value1', 'Field2' => 'Value2']`.
    * Для нескольких записей: `[['Field1' => 'Value1'], ['Field1' => 'Value2']]`.
* **Возвращает**: Ответ от API.
*   **Пример**:

    ```php
    $body = [
        ['Name' => 'Order 1', 'Status' => 'Active'],
        ['Name' => 'Order 2', 'Status' => 'Pending']
    ];
    $response = $nocodb->createRecord($body);
    print_r($response);
    // Вывод: Данные созданных записей
    ```

***

#### 6. `updateRecord(array $body)` 🔄

Обновляет одну или несколько записей в таблице.

* **Параметры**:
  * `$body` (array): Данные для обновления. Формат:
    * Для одной записи: `['Id' => 'rec_123', 'Field1' => 'Value1']`.
    * Для нескольких записей: `[['Id' => 'rec_123', 'Field1' => 'Value1'], ['Id' => 'rec_124', 'Field1' => 'Value2']]`.
* **Возвращает**: Ответ от API.
*   **Пример**:

    ```php
    $body = [
        ['Id' => 'rec_123', 'Status' => 'Completed'],
        ['Id' => 'rec_124', 'Status' => 'Cancelled']
    ];
    $response = $nocodb->updateRecord($body);
    print_r($response);
    // Вывод: Данные обновленных записей
    ```

***

#### 7. `deleteRecord(array $body)` 🗑️

Удаляет одну или несколько записей из таблицы.

* **Параметры**:
  * `$body` (array): Данные для удаления. Формат:
    * Для одной записи: `['Id' => 'rec_123']`.
    * Для нескольких записей: `[['Id' => 'rec_123'], ['Id' => 'rec_124']]`.
* **Возвращает**: Ответ от API.
*   **Пример**:

    ```php
    $body = [
        ['Id' => 'rec_123'],
        ['Id' => 'rec_124']
    ];
    $response = $nocodb->deleteRecord($body);
    print_r($response);
    // Вывод: Подтверждение удаления
    ```

***

#### 8. `buildFilter(array $body)` 🔎

Преобразует фильтры в формате Airtable в строку `where` для API NocoDB.

* **Параметры**:
  * `$body` (array): Фильтры в формате `['Field' => ['operator' => 'value']]`. Поддерживаемые операторы: `equals`, `not_equals`, `greater`, `less`, `greater_eq`, `less_eq`, `in`, `not_in`, `contains`.
* **Возвращает**: Строка в формате NocoDB для параметра `where`.
*   **Пример**:

    ```php
    $filters = [
        'Status' => ['equals' => ['Active', 'Pending'], 'not_equals' => 'Cancelled'],
        'Name' => ['contains' => 'Order']
    ];
    $where = $nocodb->buildFilter($filters);
    echo $where;
    // Вывод: (Status,eq,Active)~or(Status,eq,Pending)~and(Status,ne,Cancelled)~and(Name,like,Order)
    ```

***

#### 9. `uploadAttachment(string $fileUrl, string $fileName)` 📤

Загружает файл в хранилище NocoDB по URL.

* **Параметры**:
  * `$fileUrl` (string): URL файла для загрузки.
  * `$fileName` (string): Имя файла в хранилище NocoDB.
* **Возвращает**: Массив с ключами `success`, `message`, и `url` (или `httpCode`, `response` при ошибке).
*   **Пример**:

    ```php
    $response = $nocodb->uploadAttachment('https://example.com/file.jpg', 'file.jpg');
    print_r($response);
    // Вывод: ['success' => true, 'message' => 'Файл успешно загружен.', 'url' => '...']
    ```

***

#### 10. `uploadAttachmentsMass(array $files)` 📚

Загружает несколько файлов в хранилище NocoDB.

* **Параметры**:
  * `$files` (array): Массив файлов, каждый элемент содержит `url` (URL файла) и `title` (имя файла).
* **Возвращает**: Массив с ключами `success`, `message`, и `files` (список загруженных файлов).
* **Исключения**: `InvalidArgumentException` при некорректной структуре `$files`.
*   **Пример**:

    ```php
    $files = [
        ['url' => 'https://example.com/file1.jpg', 'title' => 'file1.jpg'],
        ['url' => 'https://example.com/file2.pdf', 'title' => 'file2.pdf']
    ];
    $response = $nocodb->uploadAttachmentsMass($files);
    print_r($response);
    // Вывод: ['success' => '1', 'message' => 'Файлы успешно загружены.', 'files' => [...]]
    ```

***

#### Приватные методы

Эти методы используются внутри класса и не предназначены для прямого вызова:

* `buildOneCondition($field, $operatorNoco, $value)`: Формирует строку условия для фильтра.
* `buildOr($field, $operator, $item)`: Формирует условие с оператором OR.
* `getOperatorNoco($operator)`: Преобразует оператор Airtable в формат NocoDB.
* `formatMultipart(array $postFields)`: Преобразует данные в формат multipart для HTTP-запросов.

### ⚠️ Лучшие практики

* **Валидация конфигурации**: Убедитесь, что `$config` содержит корректные `xc-token` и ID таблицы, иначе запросы будут отклонены.
*   **Обработка ошибок**: Оборачивайте вызовы методов в try-catch, так как класс `Request` может выбросить исключения при ошибках API или cURL.

    ```php
    try {
        $records = $nocodb->getRecords();
        print_r($records);
    } catch (Exception $e) {
        echo "Ошибка: " . $e->getMessage();
    }
    ```
* **Фильтрация**: Используйте `buildFilter` для создания сложных условий, чтобы минимизировать объем возвращаемых данных.
* **Загрузка файлов**: Проверяйте доступность URL файлов перед вызовом `uploadAttachment` или `uploadAttachmentsMass`. Убедитесь, что файлы имеют допустимый MIME-тип.
* **Логирование**: Внедрите логирование запросов, ответов и ошибок для упрощения отладки.
* **Кэширование справочников**: Справочник `$fields` можно кэшировать, если он редко меняется, чтобы сократить обращения к методу `getFields`.

***

### 🐛 Устранение неполадок

* **Ошибка авторизации**: Если запросы возвращают ошибку 401, проверьте правильность `xc-token` и его действительность в NocoDB.
* **Некорректный ID таблицы**: Если методы возвращают ошибку 404, убедитесь, что `$table_id` соответствует существующей таблице в NocoDB.
* **Ошибки загрузки файлов**:
  * Проверьте доступность `$fileUrl` и корректность `$fileName`.
  * Убедитесь, что сервер NocoDB принимает файлы указанного типа и размера.
  * Проверьте наличие свободного места в хранилище NocoDB.
* **Проблемы с фильтрами**: Если `buildFilter` формирует некорректную строку `where`, проверьте, что операторы и значения в `$body` соответствуют `$operatorsNoco`.
* **Ошибки cURL**: Если метод `Request::send` выбрасывает исключение, проверьте:
  * Доступность API (`$apiBaseUrl`).
  * Включено ли расширение cURL.
  * Корректность сети (прокси, брандмауэр).
