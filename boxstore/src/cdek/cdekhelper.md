# CdekHelper

## 📦 Документация по классу CdekHelper

Добро пожаловать в документацию по классу `CdekHelper`! 🎉 Этот PHP-класс, расположенный в пространстве имен `Cdek`, предназначен для формирования и обработки данных об упаковках для интеграции с API СДЭК. Он помогает создавать структуры данных для расчета тарифов, создания заказов и определения веса упаковок. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `CdekHelper` предоставляет набор методов для работы с данными об упаковках картона, адаптируя их под требования API СДЭК. Основные задачи класса:

* Формирование упаковок для расчета тарифов и создания заказов 📦
* Определение размеров, веса и количества коробок 📏
* Адаптация данных для различных сценариев использования в API СДЭК 🔄
* Расчет веса упаковок на основе их объема ⚖️

Класс не зависит от внешних сервисов напрямую, а работает с входными данными, предоставленными в виде массивов. Все методы оптимизированы для обработки картонных упаковок с учетом их типа, размеров и количества.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `CdekHelper`, выполните следующие шаги:

1.  **Подключите класс**: Убедитесь, что файл класса включен в ваш PHP-проект.

    ```php
    require_once 'path/to/CdekHelper.php';
    ```
2.  **Создайте экземпляр класса**: Класс не требует параметров в конструкторе, поэтому просто создайте объект.

    ```php
    use Cdek\CdekHelper;
    $cdekHelper = new CdekHelper();
    ```
3. **Подготовьте данные**: Убедитесь, что входные данные (массивы с информацией о товарах или упаковках) соответствуют ожидаемой структуре (см. примеры ниже).
4. **Используйте методы**: Вызывайте методы для формирования или обработки данных об упаковках.

***

### 📋 Методы и использование

Ниже приведен полный список методов класса `CdekHelper`, их назначение, параметры и примеры использования.

#### 1. `getPacksCardboard(array $items)` 📦

Формирует массив упаковок для СДЭК на основе списка товаров.

* **Параметры**:
  * `$items` (array): Массив товаров, каждый элемент содержит информацию о типе коробки, размерах, весе и количестве.
* **Возвращает**: Массив упаковок с данными о весе, размерах, стоимости и количестве коробок.
*   **Пример**:

    ```php
    $items = [
        [
            'quantity' => 75,
            'initialPrice' => 1000,
            'properties' => [
                'typeBox' => ['value' => '201'],
                'lGab' => ['value' => 600],
                'wGab' => ['value' => 400],
                'weightOneBox' => ['value' => 500],
                'typeCarton' => ['value' => 10]
            ]
        ]
    ];
    $packs = $cdekHelper->getPacksCardboard($items);
    print_r($packs);
    // Вывод: Массив упаковок с packageId, weight, length, width, height, amountBoxes, cost
    ```

***

#### 2. `getPackagingItem(array $item, int $packageId)` 📏

(Приватный метод) Формирует данные об упаковках для одного товара, разбивая его на несколько упаковок при необходимости.

* **Параметры**:
  * `$item` (array): Данные о товаре (количество, тип коробки, размеры, вес).
  * `$packageId` (int): Начальный ID упаковки.
* **Возвращает**: Массив упаковок для данного товара.
* **Примечание**: Этот метод вызывается автоматически в `getPacksCardboard`.

***

#### 3. `getMaxInPackage(string $typeBox)` 📊

(Приватный метод) Определяет максимальное количество коробок в одной упаковке в зависимости от типа коробки.

* **Параметры**:
  * `$typeBox` (string): Тип коробки (например, '201', '215', '330').
* **Возвращает**: Целое число (максимальное количество коробок).
* **Логика**:
  * Для типов '201', '215', '330' возвращает 50.
  * Для остальных типов — 100.

***

#### 4. `getDimensions(array $item, int $amountInPackaging)` 📐

(Приватный метод) Рассчитывает размеры упаковки (длина, ширина, высота) на основе данных о товаре.

* **Параметры**:
  * `$item` (array): Данные о товаре (размеры, тип коробки, количество).
  * `$amountInPackaging` (int): Максимальное количество коробок в упаковке.
* **Возвращает**: Массив с ключами `length`, `width`, `height`.
* **Логика**:
  * Длина и ширина берутся из свойств `lGab` и `wGab`.
  * Для типов коробок '201', '215', '330' длина делится на 2.
  * Высота рассчитывается как количество \* толщина картона.

***

#### 5. `getAmountInPackaging(int $quantity, int $amountInPackaging)` 📦

(Приватный метод) Разбивает общее количество коробок на отдельные упаковки.

* **Параметры**:
  * `$quantity` (int): Общее количество коробок.
  * `$amountInPackaging` (int): Максимальное количество коробок в одной упаковке.
* **Возвращает**: Массив с количеством коробок в каждой упаковке.
* **Пример**:
  * Для `quantity = 75` и `amountInPackaging = 50` возвращает `[50, 25]`.

***

#### 6. `getHeight(string $boxType, int $amount, $cartonType)` 📏

(Приватный метод) Рассчитывает высоту упаковки с учетом типа коробки и количества.

* **Параметры**:
  * `$boxType` (string): Тип коробки.
  * `$amount` (int): Количество коробок в упаковке.
  * `$cartonType` (mixed): Толщина картона.
* **Возвращает**: Высота упаковки (число).
* **Логика**:
  * Базовая высота = `$amount * $cartonType`.
  * Для типов '201', '215', '330', '300', '6', '1006' высота удваивается.

***

#### 7. `getTariffPacksCardboard($packagins)` 📊

Адаптирует данные упаковок для расчета тарифов в API СДЭК.

* **Параметры**:
  * `$packagins` (array): Массив упаковок (результат `getPacksCardboard`).
* **Возвращает**: Массив упаковок с преобразованными размерами и весом для API СДЭК.
*   **Пример**:

    ```php
    $packagins = [
        [
            'packageId' => 1,
            'weight' => 500,
            'length' => 600,
            'width' => 400,
            'height' => 100,
            'amountBoxes' => 50,
            'cost' => 1000
        ]
    ];
    $tariffPacks = $cdekHelper->getTariffPacksCardboard($packagins);
    print_r($tariffPacks);
    // Вывод: Массив с weight, length, width, height (в сантиметрах)
    ```

***

#### 8. `getCdekPacksCardboard($packagins)` 📦

Формирует данные упаковок для создания заказа в API СДЭК, включая информацию о содержимом.

* **Параметры**:
  * `$packagins` (array): Массив упаковок (результат `getPacksCardboard`).
* **Возвращает**: Массив упаковок с дополнительными данными (например, `items`) для API СДЭК.
*   **Пример**:

    ```php
    $packagins = [
        [
            'packageId' => 1,
            'weight' => 500,
            'length' => 600,
            'width' => 400,
            'height' => 100,
            'amountBoxes' =>"Arial, sans-serif;">50,
            'cost' => 1000
        ]
    ];
    $cdekPacks = $cdekHelper->getCdekPacksCardboard($packagins);
    print_r($cdekPacks);
    // Вывод: Массив с number, weight, length, width, height, items
    ```

***

#### 9. `getPacksWeightCardboard($packagins)` ⚖️

Рассчитывает общий вес упаковок на основе их объема.

* **Параметры**:
  * `$packagins` (array): Массив упаковок (результат `getPacksCardboard`).
* **Возвращает**: Целое число (вес в килограммах, округленный вниз).
* **Логика**:
  * Вес = (длина \* ширина \* высота) / 5000 для каждой упаковки.
  * Размеры переводятся в сантиметры.
*   **Пример**:

    ```php
    $packagins = [
        [
            'packageId' => 1,
            'weight' => 500,
            'length' => 600,
            'width' => 400,
            'height' => 100,
            'amountBoxes' => 50,
            'cost' => 1000
        ]
    ];
    $weight = $cdekHelper->getPacksWeightCardboard($packagins);
    echo $weight;
    // Вывод: Рассчитанный вес (например, 9)
    ```

***

### ⚠️ Лучшие практики

* **Валидация входных данных**: Убедитесь, что входной массив `$items` содержит все необходимые ключи (`quantity`, `initialPrice`, `properties` с `typeBox`, `lGab`, `wGab`, `weightOneBox`, `typeCarton`). Отсутствие данных может привести к ошибкам.
* **Единицы измерения**: Размеры (`length`, `width`, `height`) ожидаются в миллиметрах, а вес — в граммах. Методы `getTariffPacksCardboard` и `getCdekPacksCardboard` автоматически конвертируют размеры в сантиметры.
* **Оптимизация упаковок**: Метод `getAmountInPackaging` эффективно разбивает товары на упаковки, но проверьте, подходит ли логика для ваших сценариев (например, максимум 50 или 100 коробок в упаковке).
* **Логирование**: Внедрите логирование входных и выходных данных методов для упрощения отладки.
* **Тестирование**: Протестируйте методы с различными типами коробок и количеством товаров, чтобы убедиться в корректности расчетов.

***

### 🐛 Устранение неполадок

* **Некорректные размеры**: Если размеры или вес в результате кажутся неправильными, проверьте входные данные в `$items['properties']` (например, `lGab`, `wGab`, `typeCarton`).
* **Ошибки с типом коробки**: Убедитесь, что `typeBox` соответствует ожидаемым значениям ('201', '215', '330' и т.д.). Неизвестные типы могут привести к некорректным расчетам.
* **Пустой результат**: Если методы возвращают пустой массив, проверьте, переданы ли данные в `$items` или `$packagins` и содержат ли они все необходимые поля.
* **Высота упаковки**: Если высота (`height`) в результате кажется некорректной, проверьте логику в `getHeight` для вашего типа коробки.
