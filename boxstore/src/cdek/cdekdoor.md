# CdekDoor

## 🚪 Документация по классу CdekDoor

Добро пожаловать в документацию по классу `CdekDoor`! 🎉 Этот PHP-класс расширяет функциональность класса `Cdek` из пространства имен `Cdek` и предназначен для работы с API СДЭК, специализируясь на доставке до двери (режим доставки 3). Он предоставляет методы для расчета тарифов и создания заказов. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `CdekDoor` наследуется от класса `Cdek` и добавляет специфичную логику для операций доставки до двери. Основные задачи класса:

* Расчет тарифов для доставки до двери 📊
* Создание заказов в системе СДЭК 📦
* Фильтрация тарифов по режиму доставки (дверь) 🔍

Класс использует объект `Request` для отправки HTTP-запросов к API СДЭК и наследует авторизацию через OAuth от родительского класса `Cdek`. Все методы просты в использовании и ориентированы на конкретный сценарий доставки.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `CdekDoor`, выполните следующие шаги:

1.  **Подключите классы**: Убедитесь, что файлы классов `Cdek`, `CdekDoor` и `Request` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Cdek.php';
    require_once 'path/to/CdekDoor.php';
    require_once 'path/to/Request.php';
    ```
2. **Получите учетные данные API**: Зарегистрируйтесь в СДЭК и получите `client_id` и `client_secret` для авторизации.
3.  **Создайте экземпляр класса**: Передайте `client_id` и `client_secret` в конструктор.

    ```php
    use Cdek\CdekDoor;
    $cdekDoor = new CdekDoor('your_client_id', 'your_client_secret');
    ```
4. **Используйте методы**: Вызывайте методы для расчета тарифов или создания заказов (подробности ниже).

***

### 📋 Методы и использование

Класс `CdekDoor` наследует все методы родительского класса `Cdek` (например, `getOrder`, `getOrderByUuid`, `getShipmentPoint`) и добавляет следующие методы, специфичные для доставки до двери. Ниже описаны новые методы.

#### 1. `__construct(string $clientId, string $clientSecret)` 🛠️

Инициализирует класс, вызывая конструктор родительского класса `Cdek` для настройки авторизации и объекта `Request`. Устанавливает режим доставки (`deliveryMode`) равным 3 (дверь).

* **Параметры**:
  * `$clientId` (string): Идентификатор клиента для API СДЭК.
  * `$clientSecret` (string): Секретный ключ клиента для API СДЭК.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $cdekDoor = new CdekDoor('your_client_id', 'your_client_secret');
    ```

***

#### 2. `getTariffs($packagins, $address)` 📊

Рассчитывает доступные тарифы для доставки до двери на основе адреса доставки и данных об упаковке.

* **Параметры**:
  * `$packagins` (array): Массив с данными об упаковке (например, размеры, вес).
  * `$address` (string): Адрес доставки.
* **Возвращает**: Массив отфильтрованных тарифов (режим доставки 3, исключая тариф "Посылка маркетплейс склад-дверь")
*   **Пример**:

    ```php
    $packagins = [
        [
            'weight' => 1000, // вес в граммах
            'length' => 30,   // длина в см
            'width' => 20,    // ширина в см
            'height' => 10    // высота в см
        ]
    ];
    $address = 'г. Москва, ул. Ленина, д. 10';
    $tariffs = $cdekDoor->getTariffs($packagins, $address);
    print_r($tariffs);
    // Вывод: Массив с отфильтрованными тарифами
    ```

***

#### 3. `tariffsHandler($tariffs)` 🔍

(Приватный метод) Фильтрует тарифы, возвращая только те, которые соответствуют режиму доставки до двери (`deliveryMode = 3`) и исключая тариф "Посылка маркетплейс склад-дверь".

* **Параметры**:
  * `$tariffs` (array): Ответ от API с данными о тарифах.
* **Возвращает**: Массив отфильтрованных тарифов
* **Примечание**: Этот метод вызывается автоматически в `getTariffs`. Вам не нужно вызывать его вручную.

***

#### 4. `createCdek($data)` 📦

Создает новый заказ в системе СДЭК.

* **Параметры**:
  * `$data` (array): Массив с данными для создания заказа (структура зависит от требований API СДЭК).
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`)
*   **Пример**:

    ```php
    $data = [
        'type' => 1,
        'recipient' => [
            'name' => 'Иван Иванов',
            'phones' => ['+79991234567']
        ],
        'to_location' => [
            'address' => 'г. Москва, ул. Ленина, д. 10'
        ],
        'packages' => [
            [
                'weight' => 1000,
                'length' => 30,
                'width' => 20,
                'height' => 10
            ]
        ]
    ];
    $response = $cdekDoor->createCdek($data);
    print_r($response);
    // Вывод: Данные созданного заказа в формате, возвращаемом API
    ```

***

### ⚠️ Лучшие практики

* **Валидация данных**: Перед вызовом `getTariffs` и `createCdek` проверяйте входные данные (`packagins`, `address`, `$data`) на соответствие требованиям API СДЭК, чтобы избежать ошибок.
* **Обработка ошибок**: Класс полагается на объект `Request` для обработки HTTP-запросов. Убедитесь, что `Request` корректно обрабатывает ошибки API (например, неверные параметры или проблемы с сервером).
* **Наследование**: Поскольку `CdekDoor` наследуется от `Cdek`, вы можете использовать методы родительского класса, такие как `getOrder` или `getShipmentPoint`, для дополнительных операций.
* **Логирование**: Внедрите логирование запросов и ответов API для упрощения отладки и мониторинга.
* **Кэширование тарифов**: Если тарифы редко меняются, рассмотрите возможность кэширования результатов `getTariffs` для оптимизации производительности.

***

### 🐛 Устранение неполадок

* **Ошибки API**: Если методы `getTariffs` или `createCdek` возвращают ошибки (например, 400 или 422), проверьте правильность структуры входных данных (`packagins`, `address`, `$data`) в соответствии с документацией API СДЭК.
* **Проблемы с авторизацией**: Если запросы возвращают ошибку 401, убедитесь, что `client_id` и `client_secret` верны, а токен доступа не истек (наследуется от `Cdek`).
* **Ошибки в `Request`**: Если методы возвращают неожиданные результаты, проверьте реализацию класса `Request` на предмет корректной обработки ответов API.
* **Неверный адрес**: Убедитесь, что переданный `$address` в `getTariffs` распознается API СДЭК (например, содержит город и улицу).
