# CdekPvz

## 📍 Документация по классу CdekPvz

Добро пожаловать в документацию по классу `CdekPvz`! 🎉 Этот PHP-класс расширяет функциональность класса `Cdek` из пространства имен `Cdek` и предназначен для работы с API СДЭК, специализируясь на доставке до пунктов выдачи заказов (ПВЗ, режим доставки 4). Он предоставляет методы для расчета тарифов, получения списка ПВЗ и создания заказов. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `CdekPvz` наследуется от класса `Cdek` и добавляет специфичную логику для операций доставки до ПВЗ. Основные задачи класса:

* Расчет тарифов для доставки до пунктов выдачи 📊
* Получение списка доступных ПВЗ 🔍
* Создание заказов в системе СДЭК 📦
* Фильтрация тарифов по режиму доставки (ПВЗ) 🚚

Класс использует объект `Request` для отправки HTTP-запросов к API СДЭК и наследует авторизацию через OAuth от родительского класса `Cdek`. Все методы просты в использовании и ориентированы на сценарий доставки до ПВЗ.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `CdekPvz`, выполните следующие шаги:

1.  **Подключите классы**: Убедитесь, что файлы классов `Cdek`, `CdekPvz` и `Request` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Cdek.php';
    require_once 'path/to/CdekPvz.php';
    require_once 'path/to/Request.php';
    ```
2. **Получите учетные данные API**: Зарегистрируйтесь в СДЭК и получите `client_id` и `client_secret` для авторизации.
3.  **Создайте экземпляр класса**: Передайте `client_id` и `client_secret` в конструктор.

    ```php
    use Cdek\CdekPvz;
    $cdekPvz = new CdekPvz('your_client_id', 'your_client_secret');
    ```
4. **Используйте методы**: Вызывайте методы для расчета тарифов, получения ПВЗ или создания заказов (подробности ниже).

***

### 📋 Методы и использование

Класс `CdekPvz` наследует все методы родительского класса `Cdek` (например, `getOrder`, `getOrderByUuid`, `getShipmentPoint`) и добавляет следующие методы, специфичные для доставки до ПВЗ. Ниже описаны новые методы.

#### 1. `__construct(string $clientId, string $clientSecret)` 🛠️

Инициализирует класс, вызывая конструктор родительского класса `Cdek` для настройки авторизации и объекта `Request`. Устанавливает режим доставки (`deliveryMode`) равным 4 (ПВЗ).

* **Параметры**:
  * `$clientId` (string): Идентификатор клиента для API СДЭК.
  * `$clientSecret` (string): Секретный ключ клиента для API СДЭК.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $cdekPvz = new CdekPvz('your_client_id', 'your_client_secret');
    ```

***

#### 2. `getTariffs($packagins, $code)` 📊

Рассчитывает доступные тарифы для доставки до ПВЗ на основе кода пункта выдачи и данных об упаковке.

* **Параметры**:
  * `$packagins` (array): Массив с данными об упаковке (например, размеры, вес).
  * `$code` (string): Код пункта выдачи (ПВЗ).
* **Возвращает**: Массив отфильтрованных тарифов (режим доставки 4, исключая тариф "Посылка маркетплейс склад-склад").
*   **Пример**:

    ```php
    $packagins = [
        [
            'weight' => 1000, // вес в граммах
            'length' => 30,   // длина в см
            'width' => 20,    // ширина в см
            'height' => 10    // высота в см
        ]
    ];
    $code = 'MSK123'; // Код ПВЗ
    $tariffs = $cdekPvz->getTariffs($packagins, $code);
    print_r($tariffs);
    // Вывод: Массив с отфильтрованными тарифами
    ```

***

#### 3. `tariffsHandler($tariffs)` 🔍

(Приватный метод) Фильтрует тарифы, возвращая только те, которые соответствуют режиму доставки до ПВЗ (`deliveryMode = 4`) и исключая тариф "Посылка маркетплейс склад-склад".

* **Параметры**:
  * `$tariffs` (array): Ответ от API с данными о тарифах.
* **Возвращает**: Массив отфильтрованных тарифов.
* **Примечание**: Этот метод вызывается автоматически в `getTariffs`. Вам не нужно вызывать его вручную.

***

#### 4. `getPvz($data)` 📍

Получает список доступных пунктов выдачи (ПВЗ) на основе переданных параметров.

* **Параметры**:
  * `$data` (array): Ассоциативный массив с параметрами фильтрации (например, `city_code`, `type`).
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`).
*   **Пример**:

    ```php
    $data = [
        'city_code' => 44, // Код города (например, Москва)
        'type' => 'PVZ'    // Тип пункта выдачи
    ];
    $pvzList = $cdekPvz->getPvz($data);
    print_r($pvzList);
    // Вывод: Список ПВЗ в формате, возвращаемом API
    ```

***

#### 5. `createCdek($data)` 📦

Создает новый заказ в системе СДЭК для доставки до ПВЗ.

* **Параметры**:
  * `$data` (array): Массив с данными для создания заказа (структура зависит от требований API СДЭК).
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`).
*   **Пример**:

    ```php
    $data = [
        'type' => 1,
        'recipient' => [
            'name' => 'Иван Иванов',
            'phones' => ['+79991234567']
        ],
        'to_location' => [
            'code' => 'MSK123' // Код ПВЗ
        ],
        'packages' => [
            [
                'weight' => 1000,
                'length' => 30,
                'width' => 20,
                'height' => 10
            ]
        ]
    ];
    $response = $cdekPvz->createCdek($data);
    print_r($response);
    // Вывод: Данные созданного заказа в формате, возвращаемом API
    ```

***

### ⚠️ Лучшие практики

* **Валидация данных**: Перед вызовом `getTariffs` и `createCdek` проверяйте входные данные (`packagins`, `code`, `$data`) на соответствие требованиям API СДЭК, чтобы избежать ошибок.
* **Код ПВЗ**: Убедитесь, что `$code` в `getTariffs` соответствует реальному коду ПВЗ, который можно получить через `getPvz`.
* **Обработка ошибок**: Класс полагается на объект `Request` для обработки HTTP-запросов. Убедитесь, что `Request` корректно обрабатывает ошибки API (например, неверные параметры или проблемы с сервером).
* **Наследование**: Поскольку `CdekPvz` наследуется от `Cdek`, вы можете использовать методы родительского класса, такие как `getOrder` или `getShipmentPoint`, для дополнительных операций.
* **Логирование**: Внедрите логирование запросов и ответов API для упрощения отладки и мониторинга.
* **Кэширование ПВЗ**: Если список ПВЗ редко меняется, рассмотрите возможность кэширования результатов `getPvz` для оптимизации производительности.

***

### 🐛 Устранение неполадок

* **Ошибки API**: Если методы `getTariffs`, `getPvz` или `createCdek` возвращают ошибки (например, 400 или 422), проверьте правильность структуры входных данных (`packagins`, `code`, `$data`) в соответствии с документацией API СДЭК.
* **Проблемы с авторизацией**: Если запросы возвращают ошибку 401, убедитесь, что `client_id` и `client_secret` верны, а токен доступа не истек (наследуется от `Cdek`).
* **Ошибки в `Request`**: Если методы возвращают неожиданные результаты, проверьте реализацию класса `Request` на предмет корректной обработки ответов API.
* **Неверный код ПВЗ**: Убедитесь, что переданный `$code` в `getTariffs` или `$data['to_location']['code']` в `createCdek` существует в системе СДЭК.
