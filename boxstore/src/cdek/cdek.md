# Cdek

## 📬 Документация по классу Cdek

Добро пожаловать в документацию по классу `Cdek`! 🎉 Этот PHP-класс предназначен для взаимодействия с API СДЭК, предоставляя удобные методы для работы с заказами и точками отгрузки. Класс использует авторизацию через OAuth и отправляет запросы с помощью объекта `Request`. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `Cdek` находится в пространстве имен `Cdek` и разработан для выполнения следующих задач:

* Получение информации о заказах 📦
* Получение данных о конкретном заказе по UUID 🔍
* Управление точкой отгрузки 📍
* Авторизация через OAuth для безопасного доступа к API 🔒

Класс автоматически получает токен доступа (`access_token`) и инициализирует объект `Request` для выполнения HTTP-запросов к API СДЭК. Все методы просты в использовании и включают минимальную обработку ошибок, полагаясь на объект `Request`.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `Cdek`, выполните следующие шаги:

1.  **Подключите класс**: Убедитесь, что файл класса и зависимый класс `Request` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Cdek.php';
    require_once 'path/to/Request.php';
    ```
2. **Получите учетные данные API**: Зарегистрируйтесь в СДЭК и получите `client_id` и `client_secret` для авторизации.
3.  **Создайте экземпляр класса**: Передайте `client_id` и `client_secret` в конструктор.

    ```php
    use Cdek\Cdek;
    $cdek = new Cdek('your_client_id', 'your_client_secret');
    ```
4. **Используйте методы**: Вызывайте методы для работы с заказами или точкой отгрузки (подробности ниже).

***

### 📋 Методы и использование

Ниже приведен полный список методов класса `Cdek`, их назначение, параметры и примеры использования.

#### 1. `__construct(string $clientId, string $clientSecret)` 🛠️

Инициализирует класс, получает токен доступа и настраивает объект `Request`.

* **Параметры**:
  * `$clientId` (string): Идентификатор клиента для API СДЭК.
  * `$clientSecret` (string): Секретный ключ клиента для API СДЭК.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $cdek = new Cdek('your_client_id', 'your_client_secret');
    ```

***

#### 2. `getAccessToken()` 🔑

(Приватный метод) Получает токен доступа через OAuth, используя `client_id` и `client_secret`.

* **Параметры**: Нет
* **Возвращает**: Ничего (устанавливает свойство `$accessToken`)
* **Примечание**: Этот метод вызывается автоматически в конструкторе. Вам не нужно вызывать его вручную.

***

#### 3. `getOrder(array $data)` 📦

Получает список заказов, отфильтрованных по указанным параметрам.

* **Параметры**:
  * `$data` (array): Ассоциативный массив с параметрами фильтрации (например, `status`, `date` и т.д.).
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`)
*   **Пример**:

    ```php
    $filters = [
        'status' => 'CREATED',
        'date_from' => '2025-01-01'
    ];
    $orders = $cdek->getOrder($filters);
    print_r($orders);
    // Вывод: Данные заказов в формате, возвращаемом API
    ```

***

#### 4. `getOrderByUuid(string $uuid)` 🔍

Получает информацию о конкретном заказе по его UUID.

* **Параметры**:
  * `$uuid` (string): Уникальный идентификатор заказа.
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`)
*   **Пример**:

    ```php
    $order = $cdek->getOrderByUuid('123e4567-e89b-12d3-a456-426614174000');
    print_r($order);
    // Вывод: Данные заказа в формате, возвращаемом API
    ```

***

#### 5. `getShipmentPoint()` 📍

Возвращает код точки отгрузки (по умолчанию `VRN21`).

* **Параметры**: Нет
* **Возвращает**: Строка (код точки отгрузки)
*   **Пример**:

    ```php
    $point = $cdek->getShipmentPoint();
    echo $point;
    // Вывод: VRN21
    ```

***

### ⚠️ Лучшие практики

* **Безопасность учетных данных**: Храните `client_id` и `client_secret` в безопасном месте, например, в конфигурационном файле или переменных окружения, чтобы избежать утечек.
* **Обработка ошибок**: Класс полагается на объект `Request` для обработки HTTP-запросов. Убедитесь, что `Request` корректно обрабатывает ошибки API (например, истекший токен или неверные параметры).
* **Повторная авторизация**: Если токен доступа истекает, вам нужно будет повторно вызвать `getAccessToken`. Рассмотрите возможность добавления логики для автоматического обновления токена.
* **Логирование**: Внедрите логирование запросов и ответов API для отладки и мониторинга.
* **Кэширование токена**: Чтобы уменьшить количество запросов к `/v2/oauth/token`, кэшируйте токен доступа до его истечения (обычно 3600 секунд).

***

### 🐛 Устранение неполадок

* **Ошибка авторизации**: Если запросы возвращают ошибку 401, проверьте правильность `client_id` и `client_secret`. Убедитесь, что сервер API СДЭК доступен.
* **Проблемы с cURL**: Если метод `getAccessToken` не работает, проверьте, включено ли расширение cURL в PHP и доступен ли URL API (`https://api.cdek.ru`).
* **Ошибки в `Request`**: Если методы `getOrder` или `getOrderByUuid` возвращают неожиданные результаты, проверьте реализацию класса `Request` на предмет корректной обработки ответов API.
* **Неверный UUID**: Убедитесь, что UUID, передаваемый в `getOrderByUuid`, существует в системе СДЭК.
