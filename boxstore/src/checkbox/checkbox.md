# CheckBox

## 📦 Документация по классу CheckBox

Добро пожаловать в документацию по классу `CheckBox`! 🎉 Этот PHP-класс, расположенный в пространстве имен `CheckBox`, предназначен для проверки возможности производства коробок с заданными параметрами (модель, размеры, толщина картона, цвет). Класс интегрируется с объектом `Informator` для получения данных о цветах и размерах листов картона, обеспечивая детальную валидацию. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `CheckBox` разработан для выполнения следующих задач:

* Проверка возможности изготовления коробки на основе модели, размеров, толщины картона и цвета 📋
* Поддержка различных моделей коробок, включая FEFCO (201, 215, 300, 330, 426, 427, 933, 110, 1121) и специальные модели (1006, 1301, 1302, 1701) 📏
* Валидация размеров развертки коробки на совместимость с листами картона 🔍
* Поддержка режимов работы (`devMode`, `apiMode`, `prodMode`, `infMode`) для гибкой настройки ограничений ⚙️

Класс принимает объект `Informator` для доступа к данным о цветах и размерах листов, а также позволяет задавать пользовательские размеры листа (`manualSheetXSize`, `manualSheetYSize`). Он возвращает результаты проверки с указанием возможности производства и причин ошибок (при их наличии).

***

### 🛠️ Установка и настройка

Чтобы использовать класс `CheckBox`, выполните следующие шаги:

1.  **Подключите классы**: Убедитесь, что файлы классов `CheckBox` и `Informator` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/CheckBox.php';
    require_once 'path/to/Informator.php';
    ```
2.  **Создайте экземпляр Informator**: Настройте объект `Informator` с конфигурацией баз данных (см. документацию `Informator`).

    ```php
    use Informator\Informator;
    $config = [/* конфигурация баз данных */];
    $informator = new Informator($config);
    ```
3.  **Создайте экземпляр класса**: Передайте объект `Informator`, модель коробки, размеры, толщину картона, цвет и, при необходимости, размеры листа.

    ```php
    use CheckBox\CheckBox;
    $checkbox = new CheckBox(
        $informator,
        $model = 201,
        $length = 200,
        $width = 150,
        $height = 100,
        $thickness = 1.5,
        $colorCode = 'white',
        $manualSheetYSize = null,
        $manualSheetXSize = null
    );
    ```
4. **Используйте методы**: Вызывайте метод `canBeProduced` для проверки возможности производства коробки.

***

### 📋 Методы и использование

Класс `CheckBox` предоставляет один публичный метод `canBeProduced` для проверки возможности производства коробки и один приватный метод `maxSweepSizeCheck` для валидации размеров развертки. Ниже описаны оба метода.

#### 1. `__construct($informator, $model, $length, $width, $height, $thickness, $colorCode, $manualSheetYSize = null, $manualSheetXSize = null)` 🛠️

Инициализирует класс, устанавливая параметры коробки и объект `Informator`.

* **Параметры**:
  * `$informator` (object): Экземпляр класса `Informator`.
  * `$model` (int): Модель коробки (FEFCO или специальные: 6, 1006, 1301, 1302, 1701, 110, 1121, 201, 215, 300, 330, 426, 427, 933).
  * `$length` (float): Длина коробки, мм.
  * `$width` (float): Ширина коробки, мм.
  * `$height` (float): Высота коробки, мм.
  * `$thickness` (float): Толщина картона, мм.
  * `$colorCode` (string): Код цвета картона (на русском или английском, например, `white`, `бурый`, `LIME-BARBIE`).
  * `$manualSheetYSize` (float|null): Ручной размер листа по Y, мм (по умолчанию `null`).
  * `$manualSheetXSize` (float|null): Ручной размер листа по X, мм (по умолчанию `null`).
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $checkbox = new CheckBox($informator, 201, 200, 150, 100, 1.5, 'white');
    ```

***

#### 2. `canBeProduced()` ✅

Проверяет, возможно ли изготовить коробку с заданными параметрами.

* **Параметры**: Нет
* **Возвращает**: Массив с ключами:
  * `result` (bool): Возможность производства (`true`/`false`).
  * `error_text` (string, optional): Текст ошибки (максимум 45 символов).
* **Логика**:
  * В `devMode` все ограничения отключены, возвращается `['result' => true]`.
  * В `apiMode` проверяется корректность цвета (`$colorCode`) на основе данных `Informator`.
  * Проверяются минимальные и максимальные размеры коробки в зависимости от модели.
  * Проверяется возможность размещения развертки на листе картона с учетом `$colorCode`.
  * Учитываются соотношения размеров (например, ширина не должна превышать длину).
* **Поддерживаемые модели**:
  * Шестигранная коробка (6, 1006).
  * Негенеративные коробки (1301, 1302, 1701).
  * FEFCO (110, 1121, 201, 215, 300, 330, 426, 427, 933).
*   **Пример**:

    ```php
    try {
        $result = $checkbox->canBeProduced();
        if ($result['result']) {
            echo 'Коробка может быть произведена';
        } else {
            echo 'Ошибка: ' . $result['error_text'];
        }
        // Вывод: Коробка может быть произведена
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 3. `maxSweepSizeCheck($SizeX, $SizeY)` 📏

(Приватный метод) Проверяет, можно ли разместить развертку коробки на листе картона с учетом цвета.

* **Параметры**:
  * `$SizeX` (float): Размер развертки по X, мм.
  * `$SizeY` (float): Размер развертки по Y, мм.
* **Возвращает**: Массив с ключами:
  * `result` (bool): Возможность размещения (`true`/`false`).
  * `errorText` (string): Текст ошибки (подробный в `infMode`, общий в других режимах).
* **Логика**:
  * Определяет размеры листа в зависимости от `$colorCode`:
    * Бурый/белый: 1600x2300 мм.
    * Двухсторонний цветной (например, `LIME-BARBIE`): 1200x1600 мм.
    * Односторонний цветной: 1200x1900 мм.
  * Если `$manualSheetXSize` и `$manualSheetYSize` заданы, использует их вместо стандартных размеров.
  * В `infMode` возвращает подробные рекомендации по уменьшению размеров (длина, ширина, высота).
* **Примечание**: Вызывается автоматически в `canBeProduced`.

***

### ⚠️ Лучшие практики

*   **Обработка ошибок**: Метод `canBeProduced` может выбросить исключения, если `Informator` вызывает `PDOException`. Оборачивайте вызовы в try-catch.

    ```php
    try {
        $result = $checkbox->canBeProduced();
    } catch (Exception $e) {
        error_log('Ошибка: ' . $e->getMessage());
        echo 'Произошла ошибка';
    }
    ```
* **Валидация параметров**: Проверяйте входные параметры (`$model`, `$length`, `$width`, `$height`, `$thickness`, `$colorCode`) перед созданием экземпляра класса, чтобы избежать некорректных значений.
* **Режимы работы**:
  * Включите `devMode` (`$checkbox->devMode = true`) для тестирования без ограничений.
  * Используйте `apiMode` (`$checkbox->apiMode = true`) для строгой проверки цвета через API.
  * Активируйте `infMode` (`$checkbox->infMode = true`) для получения подробных текстов ошибок.
  * Установите `prodMode` (`$checkbox->prodMode = true`) для более строгих ограничений высоты (например, 170 мм вместо 150 мм для модели 330).
* **Цвета**: Убедитесь, что `$colorCode` соответствует значениям, возвращаемым `$informator->getCurrentColors()`, особенно в `apiMode`.
* **Ручные размеры листа**: Используйте `$manualSheetXSize` и `$manualSheetYSize` для тестирования с нестандартными листами, но проверяйте их на положительные значения.
* **Логирование**: Внедрите логирование результатов `canBeProduced` и ошибок для анализа проблем с производством.
* **Кэширование цветов**: Данные `$informator->getCurrentColors()` можно кэшировать, если они редко меняются, чтобы снизить нагрузку на базу данных.

***

### 🐛 Устранение неполадок

* **Ошибка цвета**: Если `canBeProduced` возвращает `error_text` о некорректном цвете:
  * Проверьте, что `$colorCode` соответствует значениям из `$informator->getCurrentColors()`.
  * Убедитесь, что `apiMode` включен только при необходимости строгой проверки.
* **Недоступный размер развертки**: Если возвращается `error_text` о недоступном размере:
  * Проверьте размеры коробки (`$length`, `$width`, `$height`) и толщину (`$thickness`).
  * Убедитесь, что размеры листа (`$manualSheetXSize`, `$manualSheetYSize` или стандартные для `$colorCode`) достаточны.
  * В `infMode` используйте подробные рекомендации для корректировки размеров.
* **Неизвестная модель коробки**: Если возвращается `error_text` о неизвестной модели:
  * Проверьте, что `$model` соответствует одной из поддерживаемых моделей (6, 1006, 1301, 1302, 1701, 110, 1121, 201, 215, 300, 330, 426, 427, 933).
* **Ошибки Informator**: Если возникают исключения от `Informator`:
  * Проверьте конфигурацию баз данных в `Informator`.
  * Убедитесь, что таблицы `cardboardStore` и другие существуют и содержат данные.
* **Некорректные размеры**: Если проверки размеров возвращают ошибки:
  * Проверьте минимальные и максимальные размеры для вашей модели (например, 80 мм для длины в модели 201).
  * Убедитесь, что соотношения размеров соответствуют требованиям (например, `width <= length` для моделей 201, 215, 330, 427).
