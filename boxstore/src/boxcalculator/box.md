# Box

## 📏 Документация по классу Box

Добро пожаловать в документацию по классу `Box`! 🎉 Этот PHP-класс, расположенный в пространстве имен `BoxCalculator`, реализует интерфейс `BoxInterface` и предназначен для работы с базами данных, связанными с калькуляцией коробок. Класс устанавливает подключения к трем базам данных (`cardboard_store`, `cloud_muul`, `muul_formulas_drawings`) через PDO и предоставляет основу для дальнейших расчетов и операций с коробками. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `Box` разработан как базовый компонент для калькуляции коробок, обеспечивая:

* Подключение к трем базам данных через PDO для безопасного взаимодействия 📡
* Инициализацию конфигурации и проверку ее полноты 🔧
* Реализацию интерфейса `BoxInterface` для обеспечения согласованности методов 📋

Класс предназначен для использования в системах, связанных с производством и расчетом параметров коробок, и служит основой для более сложных операций, которые могут быть добавлены в будущем. Он использует PDO для надежного и безопасного доступа к базам данных, поддерживая обработку ошибок и валидацию конфигурации.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `Box`, выполните следующие шаги:

1.  **Подключите класс и интерфейс**: Убедитесь, что файлы класса `Box` и интерфейса `BoxInterface` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Box.php';
    require_once 'path/to/BoxInterface.php';
    ```
2.  **Создайте интерфейс BoxInterface**: Убедитесь, что интерфейс `BoxInterface` существует и определяет необходимые методы. Пример:

    ```php
    namespace BoxCalculator\Interfaces;

    interface BoxInterface {
        public function initializeConnections(array $config): void;
        // Другие методы, которые могут быть добавлены
    }
    ```
3. **Настройте конфигурацию**:
   * Подготовьте массив конфигурации с данными для подключения к базам данных (`cardboard_store`, `cloud_muul`, `muul_formulas_drawings`).
   * Каждая база данных должна содержать ключи `host`, `database`, и `users.read` с `username` и `password`.
4.  **Создайте экземпляр класса**: Передайте конфигурацию в конструктор.

    ```php
    use BoxCalculator\Box;
    $config = [
        'databases' => [
            'cardboard_store' => [
                'host' => 'localhost',
                'database' => 'cardboard_store',
                'users' => [
                    'read' => [
                        'username' => 'user',
                        'password' => 'pass'
                    ]
                ]
            ],
            'cloud_muul' => [
                'host' => 'localhost',
                'database' => 'cloud_muul',
                'users' => [
                    'read' => [
                        'username' => 'user',
                        'password' => 'pass'
                    ]
                ]
            ],
            'muul_formulas_drawings' => [
                'host' => 'localhost',
                'database' => 'muul_formulas',
                'users' => [
                    'read' => [
                        'username' => 'user',
                        'password' => 'pass'
                    ]
                ]
            ]
        ]
    ];
    try {
        $box = new Box($config);
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```
5. **Используйте класс**: После инициализации класс готов к добавлению методов для работы с коробками (в текущей версии реализована только инициализация подключений).

### 📋 Методы и использование

Класс `Box` предоставляет два метода: конструктор и метод инициализации подключений. Ниже описаны оба метода.

#### 1. `__construct(array $config)` 🛠️

Инициализирует класс, сохраняя конфигурацию и вызывая метод подключения к базам данных.

* **Параметры**:
  * `$config` (array): Конфигурация с данными для баз данных (`cardboard_store`, `cloud_muul`, `muul_formulas_drawings`).
* **Возвращает**: Ничего
* **Исключения**: `Exception` при неполной конфигурации или ошибке подключения.
*   **Пример**:

    ```php
    try {
        $box = new Box($config);
        echo 'Подключение успешно установлено';
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 2. `initializeConnections(array $config)` 🔗

Устанавливает PDO-подключения к трем базам данных.

* **Параметры**:
  * `$config` (array): Конфигурация с данными для баз данных.
* **Возвращает**: Ничего
* **Исключения**:
  * `Exception` при отсутствии необходимых ключей в конфигурации.
  * `Exception` при ошибке подключения к любой из баз данных.
* **Примечание**: Вызывается автоматически в конструкторе.
*   **Пример**:

    ```php
    // Метод вызывается автоматически в конструкторе, но может быть вызван вручную для повторной инициализации
    try {
        $box->initializeConnections($newConfig);
    } catch (Exception $e) {
        echo 'Ошибка подключения: ' . $e->getMessage();
    }
    ```

***

### ⚠️ Лучшие практики

*   **Обработка ошибок**: Конструктор и `initializeConnections` выбрасывают исключения при ошибках конфигурации или подключения. Оборачивайте вызовы в try-catch.

    ```php
    try {
        $box = new Box($config);
    } catch (Exception $e) {
        error_log('Ошибка: ' . $e->getMessage());
        echo 'Произошла ошибка при инициализации';
    }
    ```
* **Валидация конфигурации**: Перед передачей `$config` проверяйте наличие всех необходимых ключей (`databases.cardboard_store`, `databases.cloud_muul`, `databases.muul_formulas_drawings`, а также `host`, `database`, `users.read.username`, `users.read.password`).
* **Безопасность учетных данных**: Храните данные для подключения (`username`, `password`) в безопасном месте, например, в конфигурационном файле или переменных окружения, чтобы избежать утечек.
*   **Режим PDO**: Текущая реализация не задает атрибуты PDO (например, `PDO::ATTR_ERRMODE`). Рекомендуется добавить настройку для строгой обработки ошибок:

    ```php
    $this->pdoCardboardStore->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    $this->pdoCloudMuul->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    $this->pdoDrawings->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    ```
* **Логирование**: Внедрите логирование ошибок подключения и операций для упрощения отладки.
* **Расширение функциональности**: Поскольку класс реализует `BoxInterface`, добавьте методы для расчета параметров коробок (например, размеров, стоимости, совместимости с листами картона) в соответствии с требованиями интерфейса.

### 🐛 Устранение неполадок

* **Ошибка конфигурации**: Если возникает исключение `Database configuration is incomplete`:
  * Проверьте, что `$config` содержит ключи `databases.cardboard_store`, `databases.cloud_muul`, `databases.muul_formulas_drawings` с подключами `host`, `database`, `users.read.username`, `users.read.password`.
* **Ошибка подключения**: Если возникает исключение `Failed to connect to databases`:
  * Проверьте правильность данных подключения (`host`, `username`, `password`, `database`).
  * Убедитесь, что сервер базы данных доступен и MySQL работает.
  * Проверьте, что пользователь имеет права на чтение для указанных баз данных.
* **Отсутствие интерфейса**: Если возникает ошибка, связанная с `BoxInterface`:
  * Убедитесь, что интерфейс `BoxInterface` определен и доступен.
  * Проверьте, что класс `Box` правильно реализует все методы интерфейса.
* **PDO ошибки**: Если возникают PDO-исключения:
  * Включите `PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION` для получения подробных сообщений об ошибках.
  * Проверьте, что MySQL-сервер поддерживает указанные базы данных и таблицы.
