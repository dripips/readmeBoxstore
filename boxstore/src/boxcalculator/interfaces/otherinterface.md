# OtherInterface

## 📋 Документация по интерфейсу OtherInterface

Добро пожаловать в документацию по интерфейсу `OtherInterface`! 🎉 Этот PHP-интерфейс, расположенный в пространстве имен `BoxCalculator\Interfaces`, определяет контракт для классов, предоставляющих вспомогательные методы для работы с данными о картоне, параметрах калькуляции, коэффициентах маржинальности, ложементах и артикулах в системе калькуляции коробок. Ниже вы найдете подробное описание методов интерфейса, их назначение и рекомендации по реализации.

***

### 🚀 Обзор

Интерфейс `OtherInterface` разработан для обеспечения единообразного доступа к данным, необходимым для калькуляции коробок, включая:

* Получение данных о подходящем картоне по цвету 📦
* Извлечение параметров калькуляции из базы данных 📋
* Расчет коэффициентов маржинальности и множителей для ложементов 🔢
* Получение данных о ячейках для коробок типа 933 (ложементы) 🧩
* Извлечение информации о цветах картона и разбор артикулов для калькуляции 🎨

Интерфейс предназначен для реализации в классах, таких как `Other`, которые взаимодействуют с базами данных (`cardboard_store`, `cloud_muul`, `muul_formulas_drawings`) и обеспечивают интеграцию с системой калькуляции коробок.

***

### 🛠️ Установка и настройка

Чтобы использовать интерфейс `OtherInterface`, выполните следующие шаги:

1.  **Подключите интерфейс**: Убедитесь, что файл интерфейса включен в ваш PHP-проект.

    ```php
    require_once 'path/to/OtherInterface.php';
    ```
2.  **Создайте реализующий класс**: Реализуйте интерфейс в классе, например, `Other`, который будет работать с PDO и базами данных.

    ```php
    namespace BoxCalculator;

    use BoxCalculator\Interfaces\OtherInterface;
    use PDO;
    use Exception;

    class Other implements OtherInterface {
        private PDO $pdoCardboardStore;
        private PDO $pdoCloudMuul;
        private PDO $pdoDrawings;

        public function __construct(PDO $pdoCardboardStore, PDO $pdoCloudMuul, PDO $pdoDrawings) {
            $this->pdoCardboardStore = $pdoCardboardStore;
            $this->pdoCloudMuul = $pdoCloudMuul;
            $this->pdoDrawings = $pdoDrawings;
        }

        // Реализация методов интерфейса (см. ниже)
    }
    ```
3.  **Инициализируйте PDO-подключения**: Передайте объекты PDO в конструктор реализующего класса.

    ```php
    $pdoCardboardStore = new PDO("mysql:host=localhost;dbname=cardboard_store", "user", "pass");
    $pdoCloudMuul = new PDO("mysql:host=localhost;dbname=cloud_muul", "user", "pass");
    $pdoDrawings = new PDO("mysql:host=localhost;dbname=muul_formulas", "user", "pass");

    $other = new Other($pdoCardboardStore, $pdoCloudMuul, $pdoDrawings);
    ```
4. **Используйте методы**: Вызывайте методы реализующего класса для получения данных или расчетов.

### 📋 Методы интерфейса

Интерфейс `OtherInterface` определяет семь методов, которые должны быть реализованы в классах. Ниже описаны их назначение, параметры, возвращаемые значения и рекомендации по реализации.

#### 1. `getCardboardForBox(string $color, bool $clientCalculationBox = false): array` 📦

Получает список подходящего картона для производства коробок по цвету.

* **Параметры**:
  * `$color` (string): Цвет картона (например, `white`, `бурый`, `LIME-BARBIE`).
  * `$clientCalculationBox` (bool): Режим расчета (для клиентов — `true`, для производства — `false`, по умолчанию `false`).
* **Возвращает**: Массив с данными о подходящем картоне (цена, размеры, толщина, цвет, ID и т.д.).
* **Рекомендации по реализации**:
  * Запрашивайте данные из таблицы `cardboardStore`, фильтруя по цвету (`colorCardboard` или `colorCardboardEn`) и `useCalculated = 1`.
  * Учитывайте `customerStatus` (для клиентов) или `productionStatus` (для производства).
  * Извлекайте рабочие области из таблицы `cardboardWorkArea` для корректировки размеров (`lSheetWork`, `wSheetWork`).
  * Получайте `id1C` из таблицы `cardboardStore1C`.
  * Используйте `priceSheetCustomer` для клиентского режима и `priceSheetProduction` для производственного.
  * Обрабатывайте ошибки базы данных через исключения.
*   **Пример использования**:

    ```php
    $cardboards = $other->getCardboardForBox('white', false);
    print_r($cardboards);
    ```

***

#### 2. `getParamsCalculated(): array` 📋

Получает основные параметры для калькуляции.

* **Параметры**: Нет
* **Возвращает**: Массив с параметрами калькуляции (имя => значение) и списком коэффициентов полезного материала (KPM).
* **Рекомендации по реализации**:
  * Запрашивайте параметры из таблицы `calculator_params` в базе `cloud_muul`.
  * Извлекайте данные из таблицы `KPM` и добавляйте их как подмассив с ключом `KPM`.
  * Формируйте ассоциативный массив для удобного доступа к параметрам.
  * Обрабатывайте ошибки базы данных через исключения.
*   **Пример использования**:

    ```php
    $params = $other->getParamsCalculated();
    print_r($params);
    ```

***

#### 3. `getMarginValue(int $amountBox, bool $itLozhement = false): int` 🔢

Получает коэффициент маржинальности на основе количества коробок.

* **Параметры**:
  * `$amountBox` (int): Количество коробок.
  * `$itLozhement` (bool): Использовать таблицу `marginLozhement` (для ложементов) или `margin` (по умолчанию `false`).
* **Возвращает**: `int` — значение коэффициента маржинальности.
* **Исключения**: Должен выбрасывать `Exception` при ошибках.
* **Рекомендации по реализации**:
  * Запрашивайте данные из таблицы `margin` или `marginLozhement` в базе `cloud_muul`.
  * Найдите максимальное значение `countBox`, меньшее или равное `$amountBox`, и верните соответствующий `margin`.
  * Если подходящего значения нет, верните значение по умолчанию или выбросьте исключение.
  * Обрабатывайте ошибки базы данных.
*   **Пример использования**:

    ```php
    try {
        $margin = $other->getMarginValue(100);
        echo $margin;
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

#### 4. `getCountMultiply(int $amountBox): int` 🔢

Получает множитель для коэффициента добавочного по количеству для коробок типа 933.

* **Параметры**:
  * `$amountBox` (int): Количество коробок.
* **Возвращает**: `int` — значение множителя.
* **Исключения**: Должен выбрасывать `Exception` при ошибках.
* **Рекомендации по реализации**:
  * Запрашивайте значения `countBox` из таблицы `margin` в базе `cloud_muul`.
  * Подсчитайте количество записей, где `countBox` больше `$amountBox` и меньше 1500.
  * Сортируйте результаты по убыванию для корректного подсчета.
  * Обрабатывайте ошибки базы данных.
*   **Пример использования**:

    ```php
    try {
        $multiplier = $other->getCountMultiply(100);
        echo $multiplier;
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

#### 5. `getCellList933($cells)` 🧩

Получает данные о ячейках для коробок типа 933 (ложементов).

* **Параметры**:
  * `$cells` (int): Количество ячеек.
* **Возвращает**: Массив с данными о ячейках (`cell_number_l`, `cell_number_w`) или пустой массив при ошибке.
* **Рекомендации по реализации**:
  * Запрашивайте данные из таблицы `cells_0933` в базе `muul_formulas_drawings` по значению `amount = $cells`.
  * Возвращайте первый результат (или пустой массив, если данных нет).
  * Обрабатывайте ошибки базы данных, хотя метод не требует выбрасывания исключений.
*   **Пример использования**:

    ```php
    $cellData = $other->getCellList933(4);
    print_r($cellData);
    ```

***

#### 6. `getColorsById(int $cardboardId, string $mode = 'full')` 🎨

Получает информацию о цвете картона по его ID.

* **Параметры**:
  * `$cardboardId` (int): ID картона из таблицы `cardboardColors`.
  * `$mode` (string): Режим вывода (`full` — все данные, `en` — английское название, `ru` — русское название, по умолчанию `full`).
* **Возвращает**:
  * Для `full`: Массив с ключами `success` и `data` (или `message` при ошибке).
  * Для `en`/`ru`: Строка с названием цвета или `'-'` при отсутствии.
* **Рекомендации по реализации**:
  * Запрашивайте данные из таблицы `cardboardColors` по `cardboardID`.
  * Для режима `full` возвращайте весь результат запроса.
  * Для режимов `en` и `ru` извлекайте поля `cardboardNameEn` и `cardboardNameRu` соответственно.
  * Обрабатывайте случаи, когда данные не найдены, возвращая сообщение об ошибке.
  * Обрабатывайте ошибки базы данных через исключения.
*   **Пример использования**:

    ```php
    $color = $other->getColorsById(1, 'en');
    echo $color; // Вывод: 'white'
    $fullData = $other->getColorsById(1);
    print_r($fullData);
    ```

***

#### 7. `getDataForCalculation(string $article): array` 📋

Разбирает артикул товара и возвращает данные для калькуляции.

* **Параметры**:
  * `$article` (string): Артикул в формате `TYPE-CARDBOARD-COLOR-LENGTH-WIDTH-HEIGHT-QUANTITY-GROUP` или с цветом как список ID.
* **Возвращает**: Массив с ключами `success` и `data` (список разобранных данных).
* **Рекомендации по реализации**:
  * Используйте регулярное выражение для разбора артикула (например, `/(?P<type>\d+)-(?P<cardboard>[A-Z0-9]+)-(?P<color>[A-Z\d-]+)-(?P<length>\d+)-(?P<width>\d+)-(?P<height>\d+)-(?P<quantity>\d+)-(?P<group>[A-Za-z0-9_]+)/m`).
  * Если цвет содержит буквы (например, `WHITE`), возвращайте данные как есть.
  * Если цвет — список ID (например, `1-2`), вызывайте `getColorsById` для каждого ID и формируйте подтипы (`TYPE_1`, `TYPE_2` и т.д.).
  * Убедитесь, что артикул соответствует формату, иначе возвращайте ошибку.
*   **Пример использования**:

    ```php
    $data = $other->getDataForCalculation('0427-CARDBOARD-WHITE-200-150-100-10-XXX');
    print_r($data);
    ```

### 🐛 Устранение неполадок

* **Ошибки базы данных**:
  * Проверьте, что PDO-объекты настроены корректно и имеют доступ к базам данных.
  * Убедитесь, что таблицы и поля существуют (например, `cardboardStore.useCalculated`, `cells_0933.amount`).
* **Пустые результаты**:
  * Для `getCardboardForBox`: Проверьте, что `$color` соответствует значениям в `colorCardboard` или `colorCardboardEn`, и что есть записи с `useCalculated = 1`.
  * Для `getParamsCalculated`: Убедитесь, что таблицы `calculator_params` и `KPM` содержат данные.
  * Для `getCellList933`: Проверьте, что `$cells` соответствует значению в `cells_0933.amount`.
* **Некорректные коэффициенты**:
  * Проверьте таблицы `margin` и `marginLozhement` на наличие подходящих значений `countBox`.
  * Убедитесь, что `$amountBox` — положительное число.
* **Ошибки артикулов**:
  * Проверьте формат `$article` с помощью регулярного выражения.
  * Для цветов в формате ID убедитесь, что ID существуют в `cardboardColors`.
* **Отсутствие данных**:
  * Проверьте, что `cardboardStore1C` содержит `id1C` для всех `cardboardID`.
  * Убедитесь, что `cardboardColors` содержит записи для всех используемых `cardboardID`.
