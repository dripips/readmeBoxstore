# Yandex

## 🛒 Документация по классу Yandex

Добро пожаловать в документацию по классу `Yandex`! 🎉 Этот PHP-класс, расположенный в пространстве имен `Yandex`, предназначен для взаимодействия с API Яндекс Маркета (Yandex Market) для управления заказами, получения данных о доставке и генерации этикеток. Класс использует объект `Request` для отправки HTTP-запросов и поддерживает авторизацию через токен. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `Yandex` разработан для упрощения работы с API Яндекс Маркета, предоставляя следующие возможности:

* Получение информации о конкретном заказе или списке заказов 📋
* Обновление статуса заказа 🔄
* Получение данных для этикеток доставки и их генерация в формате PDF 📦
* Авторизация через Bearer-токен для безопасного доступа 🔒

Класс интегрируется с кампанией Яндекс Маркета через `campaignId` и использует объект `Request` для выполнения всех HTTP-запросов. Он идеально подходит для автоматизации процессов управления заказами и логистики.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `Yandex`, выполните следующие шаги:

1.  **Подключите классы**: Убедитесь, что файлы классов `Yandex` и `Request` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Yandex.php';
    require_once 'path/to/Request.php';
    ```
2. **Получите учетные данные API**:
   * Зарегистрируйтесь в Яндекс Маркете и получите `campaignId` (ID вашей кампании).
   * Получите Bearer-токен для авторизации в API.
3.  **Создайте экземпляр класса**: Передайте `campaignId` и токен в конструктор.

    ```php
    use Yandex\Yandex;
    $yandex = new Yandex('your_campaign_id', 'your_bearer_token');
    ```
4. **Используйте методы**: Вызывайте методы для работы с заказами, статусами или этикетками (подробности ниже).

***

### 📋 Методы и использование

Ниже приведен полный список методов класса `Yandex`, их назначение, параметры и примеры использования.

#### 1. `__construct($campaignId, $token)` 🛠️

Инициализирует класс, устанавливая базовый URL API и объект `Request` с авторизацией.

* **Параметры**:
  * `$campaignId` (int|string): ID кампании в Яндекс Маркете.
  * `$token` (string): Bearer-токен для авторизации.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $yandex = new Yandex('123456', 'your_bearer_token');
    ```

***

#### 2. `getOrder(int $orderId)` 📋

Получает информацию о конкретном заказе по его ID.

* **Параметры**:
  * `$orderId` (int): ID заказа.
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`).
*   **Пример**:

    ```php
    try {
        $order = $yandex->getOrder(789);
        print_r($order);
        // Вывод: Данные заказа
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 3. `getOrders($body)` 📊

Получает список заказов с возможностью фильтрации.

* **Параметры**:
  * `$body` (array): Ассоциативный массив с параметрами фильтрации (например, `status`, `fromDate`, `toDate`).
* **Возвращает**: Ответ от API (зависит от реализации класса `Request`).
*   **Пример**:

    ```php
    $filters = [
        'status' => 'PROCESSING',
        'fromDate' => '2025-01-01',
        'toDate' => '2025-12-31'
    ];
    try {
        $orders = $yandex->getOrders($filters);
        print_r($orders);
        // Вывод: Список заказов
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 4. `editOrder($orderId, $body)` 🔄

Обновляет статус заказа.

* **Параметры**:
  * `$orderId` (int): ID заказа.
  * `$body` (array): Данные для обновления (например, новый статус).
* **Возвращает**: Ответ от API.
*   **Пример**:

    ```php
    $body = [
        'status' => 'SHIPPED'
    ];
    try {
        $response = $yandex->editOrder(789, $body);
        print_r($response);
        // Вывод: Подтверждение обновления
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 5. `getLabelData($orderId)` 📦

Получает данные для этикетки доставки заказа.

* **Параметры**:
  * `$orderId` (int): ID заказа.
* **Возвращает**: Ответ от API с данными этикетки.
*   **Пример**:

    ```php
    try {
        $labelData = $yandex->getLabelData(789);
        print_r($labelData);
        // Вывод: Данные для этикетки
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 6. `getLabel($orderId)` 📄

Генерирует PDF-этикетку для заказа в формате A7 и сохраняет её на сервере, возвращая URL для доступа.

* **Параметры**:
  * `$orderId` (int): ID заказа.
* **Возвращает**: Строка — URL сохраненного PDF-файла.
*   **Пример**:

    ```php
    try {
        $url = $yandex->getLabel(789);
        echo $url;
        // Вывод: https://cloud.muul.ru/barcodes/yandex/789.pdf
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

### ⚠️ Лучшие практики

*   **Обработка ошибок**: Класс `Request` может выбрасывать исключения при ошибках API или cURL. Оборачивайте вызовы методов в try-catch.

    ```php
    try {
        $orders = $yandex->getOrders([]);
    } catch (Exception $e) {
        error_log('Ошибка: ' . $e->getMessage());
        echo 'Произошла ошибка';
    }
    ```
* **Безопасность токена**: Храните `$token` в безопасном месте (например, в конфигурационном файле или переменных окружения), чтобы избежать утечек.
* **Проверка пути сохранения**: Убедитесь, что директория `/var/www/cloud.muul.ru/public_html/barcodes/yandex/` существует и доступна для записи перед вызовом `getLabel`.
* **Валидация параметров**: Проверяйте `$orderId` и `$body` на корректность перед отправкой запросов, чтобы соответствовать требованиям API Яндекс Маркета.
* **Логирование**: Внедрите логирование запросов, ответов и операций с файлами для упрощения отладки и мониторинга.
* **Кэширование**: Если данные заказов или этикеток редко меняются, рассмотрите кэширование результатов для оптимизации производительности.

***

### 🐛 Устранение неполадок

* **Ошибка авторизации (401)**: Если запросы возвращают ошибку 401, проверьте:
  * Правильность `$token` и его срок действия.
  * Корректность `$campaignId`.
* **Ошибка API (400, 404, 422)**: Проверьте:
  * Корректность `$orderId` (существует ли заказ).
  * Соответствие структуры `$body` требованиям API Яндекс Маркета.
* **Проблемы с сохранением PDF**:
  * Убедитесь, что директория `/var/www/cloud.muul.ru/public_html/barcodes/yandex/` существует и имеет права на запись.
  * Проверьте, возвращает ли `Request::send` корректный PDF-контент в `raw_response`.
* **Ошибки cURL**: Если метод `Request::send` выбрасывает исключение:
  * Проверьте доступность API (`https://api.partner.market.yandex.ru`).
  * Убедитесь, что расширение cURL включено в PHP.
  * Проверьте сетевые настройки (прокси, брандмауэр).
* wannabe **Некорректный ответ API**: Если ответ не содержит ожидаемых данных, проверьте документацию API Яндекс Маркета и убедитесь, что запросы соответствуют спецификации.
