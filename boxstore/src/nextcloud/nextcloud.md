# Nextcloud

## ☁️ Документация по классу Nextcloud

Добро пожаловать в документацию по классу `Nextcloud`! 🎉 Этот PHP-класс, расположенный в пространстве имен `Nextcloud`, предназначен для взаимодействия с Nextcloud через протокол WebDAV. Он предоставляет методы для получения списка файлов с фильтрацией по артикулу или имени файла, что удобно для работы с чертежами и другими файлами. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `Nextcloud` разработан для упрощения работы с файлами в облачном хранилище Nextcloud, используя WebDAV API. Основные задачи класса:

* Получение списка файлов с фильтрацией по артикулу или имени файла 🔍
* Поддержка работы с файлами определенного расширения (например, `.dxf`) 📁
* Авторизация через логин и пароль для безопасного доступа 🔒

Класс использует cURL для выполнения WebDAV-запросов (метод PROPFIND) и парсит XML-ответы для извлечения информации о файлах. Он идеально подходит для сценариев, связанных с управлением чертежами или другими файлами в Nextcloud.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `Nextcloud`, выполните следующие шаги:

1.  **Подключите класс**: Убедитесь, что файл класса включен в ваш PHP-проект.

    ```php
    require_once 'path/to/Nextcloud.php';
    ```
2. **Убедитесь в наличии зависимостей**:
   * Расширение cURL должно быть включено в PHP.
   * Библиотека `simplexml` для парсинга XML-ответов также должна быть доступна.
3. **Получите учетные данные Nextcloud**:
   * Логин и пароль пользователя Nextcloud.
   * URL для WebDAV (обычно вида `https://your-domain.com/remote.php/dav/files/username/`).
   * Домен Nextcloud (например, `your-domain.com`).
4.  **Создайте экземпляр класса**: Передайте конфигурацию с учетными данными.

    ```php
    use Nextcloud\Nextcloud;
    $config = [
        'nextcloud' => [
            'username' => 'your_username',
            'password' => 'your_password',
            'webdav_url' => 'https://your-domain.com/remote.php/dav/files/',
            'domain' => 'your-domain.com'
        ]
    ];
    $nextcloud = new Nextcloud($config);
    ```
5. **Используйте методы**: Вызывайте методы для получения списка файлов (подробности ниже).

***

### 📋 Методы и использование

Класс `Nextcloud` предоставляет два публичных метода для получения файлов и один приватный метод для выполнения WebDAV-запросов. Ниже описаны все методы.

#### 1. `__construct($config)` 🛠️

Инициализирует класс, устанавливая учетные данные и URL для WebDAV.

* **Параметры**:
  * `$config` (array): Конфигурация с ключами:
    * `nextcloud.username` (string): Имя пользователя Nextcloud.
    * `nextcloud.password` (string): Пароль пользователя.
    * `nextcloud.webdav_url` (string): Базовый URL для WebDAV.
    * `nextcloud.domain` (string): Домен Nextcloud.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $config = [
        'nextcloud' => [
            'username' => 'user',
            'password' => 'pass',
            'webdav_url' => 'https://cloud.example.com/remote.php/dav/files/',
            'domain' => 'cloud.example.com'
        ]
    ];
    $nextcloud = new Nextcloud($config);
    ```

***

#### 2. `getFilesPlasticByArticle($article, $depth = 15)` 📁

Получает список файлов, путь к которым содержит указанный артикул, с фильтрацией по расширению `.dxf`.

* **Параметры**:
  * `$article` (string): Артикул для фильтрации (подстрока в пути файла).
  * `$depth` (int): Глубина поиска в структуре папок (по умолчанию 15).
* **Возвращает**: Массив файлов с ключами `title` (имя файла) и `url` (ссылка на файл).
*   **Пример**:

    ```php
    $files = $nextcloud->getFilesPlasticByArticle('ART123');
    print_r($files);
    // Вывод: [
    //     ['title' => 'ART123_design.dxf', 'url' => 'https://user:pass@cloud.example.com/.../ART123_design.dxf'],
    //     ...
    // ]
    ```

***

#### 3. `getFilesCardboardByName($name, $extension, $depth = 15)` 📄

Получает список файлов, имя которых точно соответствует указанному имени и расширению.

* **Параметры**:
  * `$name` (string): Имя файла (без расширения).
  * `$extension` (string): Расширение файла (например, `dxf`).
  * `$depth` (int): Глубина поиска в структуре папок (по умолчанию 15).
* **Возвращает**: Массив файлов с ключами `title` (имя файла) и `url` (ссылка на файл).
*   **Пример**:

    ```php
    $files = $nextcloud->getFilesCardboardByName('design123', 'dxf');
    print_r($files);
    // Вывод: [
    //     ['title' => 'design123.dxf', 'url' => 'https://user:pass@cloud.example.com/.../design123.dxf'],
    //     ...
    // ]
    ```

***

#### 4. `get_webdav_files($url, $username, $password, $depth = 1, $filter = '', $extension = 'dxf', $flag = 0)` 🔍

(Приватный метод) Выполняет WebDAV-запрос PROPFIND для получения списка файлов с фильтрацией.

* **Параметры**:
  * `$url` (string): URL для WebDAV.
  * `$username` (string): Имя пользователя.
  * `$password` (string): Пароль.
  * `$depth` (int): Глубина поиска.
  * `$filter` (string): Подстрока для фильтрации пути или имени файла.
  * `$extension` (string): Расширение файла (по умолчанию `dxf`).
  * `$flag` (int): Режим фильтрации (0 — по подстроке в пути, 1 — по точному имени файла).
* **Возвращает**: Массив файлов с ключами `title` и `url`.
* **Примечание**: Этот метод вызывается автоматически в `getFilesPlasticByArticle` и `getFilesCardboardByName`.

### ⚠️ Лучшие практики

* **Безопасность учетных данных**: Храните `username` и `password` в безопасном месте (например, в конфигурационном файле или переменных окружения), чтобы избежать утечек.
*   **Обработка ошибок**: Метод `get_webdav_files` завершает выполнение скрипта при ошибке HTTP (не 207). Рекомендуется модифицировать метод для возврата исключений вместо `die`.

    ```php
    try {
        $files = $nextcloud->getFilesPlasticByArticle('ART123');
        print_r($files);
    } catch (Exception $e) {
        echo "Ошибка: " . $e->getMessage();
    }
    ```
* **Глубина поиска**: Устанавливайте разумное значение `$depth` (например, 1–5), чтобы избежать перегрузки сервера при большом количестве файлов.
* **Фильтрация**: Используйте точные артикулы или имена файлов для минимизации ненужных результатов. Папка `/DEV/` автоматически исключается из результатов.
* **Логирование**: Внедрите логирование запросов и ответов для упрощения отладки (например, логируйте HTTP-код и XML-ответ).
* **Кэширование**: Если список файлов редко меняется, кэшируйте результаты методов `getFilesPlasticByArticle` и `getFilesCardboardByName` для оптимизации производительности.

***

### 🐛 Устранение неполадок

* **Ошибка HTTP (не 207)**: Если метод завершает выполнение с ошибкой "Ошибка WebDAV: HTTP $code":
  * Проверьте правильность `webdav_url`, `username` и `password`.
  * Убедитесь, что сервер Nextcloud доступен и WebDAV включен.
  * Проверьте наличие SSL-сертификата (если используется HTTPS).
* **Пустой список файлов**:
  * Убедитесь, что `$article` или `$name` соответствуют существующим файлам.
  * Проверьте, что файлы имеют указанное расширение (например, `dxf`).
  * Убедитесь, что файлы не находятся в папке `/DEV/`.
* **Проблемы с cURL**:
  * Проверьте, включено ли расширение cURL в PHP.
  * Убедитесь, что сетевые настройки (прокси, брандмауэр) не блокируют запросы.
* **Ошибки парсинга XML**: Если ответ не парсится, проверьте, включена ли библиотека `simplexml` и корректен ли XML-ответ от сервера.
