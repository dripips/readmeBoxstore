# Wildberries

## 🛍️ Документация по классу Wildberries

Добро пожаловать в документацию по классу `Wildberries`! 🎉 Этот PHP-класс, расположенный в пространстве имен `Wildberries`, предназначен для взаимодействия с API Wildberries Marketplace. Он предоставляет методы для управления сборочными заданиями, поставками, статусами и генерации стикеров. Класс использует объект `Request` для отправки HTTP-запросов и поддерживает авторизацию через API-ключ. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `Wildberries` разработан для упрощения работы с API Wildberries Marketplace, предоставляя следующие возможности:

* Получение новых и всех сборочных заданий 📋
* Получение статусов сборочных заданий 🔍
* Создание поставок и перевод их в доставку 📦
* Генерация стикеров для заданий и поставок 🏷️
* Авторизация через Bearer-токен для безопасного доступа 🔒

Класс интегрируется с API Wildberries через базовый URL и использует объект `Request` для выполнения HTTP-запросов. Он идеально подходит для автоматизации процессов управления заказами, поставками и логистикой на платформе Wildberries.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `Wildberries`, выполните следующие шаги:

1.  **Подключите классы**: Убедитесь, что файлы классов `Wildberries` и `Request` включены в ваш PHP-проект.

    ```php
    require_once 'path/to/Wildberries.php';
    require_once 'path/to/Request.php';
    ```
2. **Получите учетные данные API**:
   * Зарегистрируйтесь в Wildberries Marketplace и получите API-ключ (Bearer-токен) для авторизации.
3.  **Создайте экземпляр класса**: Передайте API-ключ в конструктор.

    ```php
    use Wildberries\Wildberries;
    $wildberries = new Wildberries('your_api_key');
    ```
4. **Используйте методы**: Вызывайте методы для работы с заданиями, поставками или стикерами (подробности ниже).

### 📋 Методы и использование

Ниже приведен полный список методов класса `Wildberries`, их назначение, параметры и примеры использования.

#### 1. `__construct(string $apiKey)` 🛠️

Инициализирует класс, устанавливая базовый URL API и объект `Request` с авторизацией.

* **Параметры**:
  * `$apiKey` (string): API-ключ (Bearer-токен) для авторизации.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $wildberries = new Wildberries('your_api_key');
    ```

***

#### 2. `getNewAssemblyTasks()` 📋

Получает список новых сборочных заданий.

* **Параметры**: Нет
* **Возвращает**: Массив сборочных заданий.
*   **Пример**:

    ```php
    try {
        $tasks = $wildberries->getNewAssemblyTasks();
        print_r($tasks);
        // Вывод: Массив новых сборочных заданий
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 3. `getAssemblyTasks(array $body)` 📊

Получает список всех сборочных заданий с возможностью фильтрации и пагинации.

* **Параметры**:
  * `$body` (array): Параметры запроса:
    * `limit` (int, required): Количество заданий (от 1 до 1000).
    * `next` (int, required): Номер задания, с которого начать (0 для первого запроса).
    * `dateFrom` (int, optional): Начало периода (Unix timestamp).
    * `dateTo` (int, optional): Конец периода (Unix timestamp).
* **Возвращает**: Массив сборочных заданий.
*   **Пример**:

    ```php
    $body = [
        'limit' => 100,
        'next' => 0,
        'dateFrom' => strtotime('2025-01-01'),
        'dateTo' => strtotime('2025-12-31')
    ];
    try {
        $tasks = $wildberries->getAssemblyTasks($body);
        print_r($tasks);
        // Вывод: Массив сборочных заданий
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

#### 4. `getStatuses($body)` 🔍

Получает статусы указанных сборочных заданий.

* **Параметры**:
  * `$body` (array): Данные запроса:
    * `orders` (array, required): Массив ID сборочных заданий.
* **Возвращает**: Массив статусов заданий.
*   **Пример**:

    ```php
    $body = [
        'orders' => [123, 456, 789]
    ];
    try {
        $statuses = $wildberries->getStatuses($body);
        print_r($statuses);
        // Вывод: Массив статусов заданий
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

* **Возвращает**: Ответ от API с данными созданной поставки.
*   **Пример**:

    ```php

    ];
    ```

### ⚠️ Лучшие практики

*   **Обработка ошибок**: Класс `Request` может выбрасывать исключения при ошибках API или cURL. Оборачивайте вызовы методов в try-catch.

    ```php
    try {
        $tasks = $wildberries->getNewAssemblyTasks();
        print_r($tasks);
    } catch (Exception $e) {
        error_log('Ошибка: ' . $e->getMessage());
        echo 'Произошла ошибка';
    }
    ```
* **Безопасность API-ключа**: Храните `$apiKey` в безопасном месте (например, в конфигурационном файле или переменных окружения), чтобы избежать утечек.
* **Валидация параметров**: Проверяйте `$body` на наличие обязательных полей (например, `limit`, `next`, `orders`, `name`) и их корректность перед отправкой запросов.
* **Ограничения API**: Учитывайте ограничения API Wildberries, такие как максимум 1000 записей в `getAssemblyTasks` или максимальная длина названия поставки (128 символов).
* **Логирование**: Внедрите логирование запросов, ответов и операций со стикерами для упрощения отладки и мониторинга.
* **Кэширование**: Если данные заданий или стикеров редко меняются, рассмотрите кэширование результатов для оптимизации производительности.

### 🐛 Устранение неполадок

* **Ошибка авторизации (401)**: Если запросы возвращают ошибку 401, проверьте:
  * Правильность `$apiKey` и его срок действия.
  * Корректность базового URL API (`$apiBaseUrl`).
* **Ошибка API (400, 404, 422)**: Проверьте:
  * Корректность структуры `$body` (наличие обязательных полей, правильные типы данных).
  * Существование `$supplyId` или ID заданий в `orders`.
  * Соответствие параметров документации API Wildberries.
* **Ошибки cURL**: Если метод `Request::send` выбрасывает исключение:
  * Проверьте доступность API (`https://marketplace-api.wildberries.ru`).
  * Убедитесь, что расширение cURL включено в PHP.
  * Проверьте сетевые настройки (прокси, брандмауэр).
* **Пустой ответ**: Если методы возвращают пустой массив, проверьте:
  * Наличие данных в Wildberries (например, новых заданий или поставок).
  * Корректность фильтров в `$body` (например, `dateFrom`, `dateTo`).
* **Проблемы со стикерами**: Если `getTaskBarcode` или `getSupplyBarcode` не возвращают ожидаемые данные, убедитесь, что:
  * Указаны корректные ID заданий или поставок.
  * API поддерживает запрошенный формат (PNG, размеры 40x30 мм).
