# PlasticStore

## 🛠️ Документация по классу PlasticStore

Добро пожаловать в документацию по классу `PlasticStore`! 🎉 Этот PHP-класс, расположенный в пространстве имен `PlasticStore`, предназначен для управления компонентами и продуктами в складской системе, работающей с пластиковыми изделиями. Класс взаимодействует с базой данных через PDO и предоставляет методы для обновления количества компонентов, а также получения информации о компонентах и продуктах. Ниже вы найдете подробное руководство по использованию, описание методов и рекомендации по внедрению.

***

### 🚀 Обзор

Класс `PlasticStore` разработан для выполнения следующих задач:

* Обновление количества компонентов на разных стадиях производства (резка, ставка, готовность) 🔄
* Получение списка всех компонентов и продуктов на складе 📋
* Поиск компонентов и продуктов по ID, имени или артикулу 🔍

Класс использует PDO для безопасного взаимодействия с базой данных, применяя транзакции для обеспечения целостности данных и обработку ошибок для надежности. Он подходит для управления складскими запасами пластиковых компонентов и готовых изделий.

***

### 🛠️ Установка и настройка

Чтобы использовать класс `PlasticStore`, выполните следующие шаги:

1.  **Подключите класс**: Убедитесь, что файл класса включен в ваш PHP-проект.

    ```php
    require_once 'path/to/PlasticStore.php';
    ```
2.  **Настройте подключение PDO**: Создайте экземпляр PDO для подключения к базе данных.

    ```php
    $dsn = 'mysql:host=localhost;dbname=your_database';
    $username = 'your_username';
    $password = 'your_password';
    $pdo = new PDO($dsn, $username, $password);
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    ```
3.  **Создайте экземпляр класса**: Передайте экземпляр PDO в конструктор.

    ```php
    use PlasticStore\PlasticStore;
    $plasticStore = new PlasticStore($pdo);
    ```
4. **Используйте методы**: Вызывайте методы для управления компонентами и продуктами (подробности ниже).

### 📋 Методы и использование

Ниже приведен полный список методов класса `PlasticStore`, их назначение, параметры и примеры использования.

#### 1. `__construct(PDO $pdo)` 🛠️

Инициализирует класс с подключением PDO.

* **Параметры**:
  * `$pdo` (PDO): Экземпляр PDO для работы с базой данных.
* **Возвращает**: Ничего
*   **Пример**:

    ```php
    $pdo = new PDO('mysql:host=localhost;dbname=warehouse', 'user', 'pass');
    $plasticStore = new PlasticStore($pdo);
    ```

***

#### 2. `updateComponentById(int $id, string $action, float $amount)` 🔄

Обновляет количество компонента на складе в зависимости от указанного действия (`cut`, `bet`, `ready`).

* **Параметры**:
  * `$id` (int): ID компонента.
  * `$action` (string): Действие (`cut` — добавить к резке, `bet` — переместить из резки в ставку, `ready` — переместить из ставки в готовые).
  * `$amount` (float): Количество для обновления.
* **Возвращает**: `true`, если обновление успешно, `false` — если запись не изменена.
* **Исключения**:
  * `InvalidArgumentException`: Если `$action` не является `cut`, `bet` или `ready`.
  * `Exception`: При ошибке базы данных.
*   **Пример**:

    ```php
    try {
        $result = $plasticStore->updateComponentById(1, 'cut', 10.5);
        echo $result ? 'Компонент обновлен' : 'Компонент не найден';
    } catch (Exception $e) {
        echo 'Ошибка: ' . $e->getMessage();
    }
    ```

***

### ⚠️ Лучшие практики

*   **Обработка ошибок**: Все методы выбрасывают исключения при ошибках базы данных. Оборачивайте вызовы в try-catch для корректной обработки.

    ```php
    try {
        $component = $plasticStore->getComponentById(1);
    } catch (Exception $e) {
        error_log('Ошибка: ' . $e->getMessage());
        echo 'Произошла ошибка';
    }
    ```
* **Транзакции**: Метод `updateComponentById` использует транзакции для обеспечения целостности данных. Убедитесь, что ваша база данных поддерживает транзакции (например, InnoDB для MySQL).
* **Валидация входных данных**: Перед вызовом `updateComponentById` проверяйте `$amount` на положительное значение и `$action` на соответствие допустимым значениям (`cut`, `bet`, `ready`).
* **Логирование**: Внедрите логирование операций (например, обновлений компонентов) для отслеживания изменений на складе.
* **Схема базы данных**: Убедитесь, что таблицы `components` и `products` существуют и содержат необходимые поля (например, `id`, `name`, `article`, `cut`, `bet`, `ready` для `components`).

***

### 🐛 Устранение неполадок

* **Ошибка PDO**: Если методы выбрасывают исключения с сообщением "Ошибка: ...", проверьте:
  * Корректность подключения к базе данных (DSN, логин, пароль).
  * Включен ли режим `PDO::ERRMODE_EXCEPTION`.
  * Существование таблиц `components` и `products`.
* **Компонент/продукт не найден**: Если методы `getComponentBy*` или `getProductBy*` возвращают `null`, проверьте:
  * Существование записи с указанным ID, именем или артикулом.
  * Корректность переданных параметров (например, отсутствие пробелов в `$name` или `$article`).
* **Обновление не выполнено**: Если `updateComponentById` возвращает `false`:
  * Проверьте, существует ли компонент с указанным `$id`.
  * Убедитесь, что `$amount` не приводит к отрицательным значениям в полях `cut` или `bet` (если база данных имеет ограничения).
* **Недопустимое действие**: Если возникает `InvalidArgumentException`, убедитесь, что `$action` — это `cut`, `bet` или `ready`.
