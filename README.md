# 📚 Вступление

Добро пожаловать в техническую документацию проекта BoxStore!\
Здесь собрана вся информация, необходимая для понимания и развития платформы.

***

### 🧭 Структура

Проект разделён на два ключевых раздела:

#### 📁 BOXSTORE — Административная панель

* Панель управления заказами, пользователями, складом, ценами и другими сущностями.
* Интеграции с маркетплейсами (OZON, Wildberries).
* Инструменты для менеджеров и операторов.

👉 Подробнее: раздел BOXSTORE

#### 🌐 PLATFORM — Клиентская платформа

* Витрина сайта и публичная часть.
* Каталог товаров, поиск, корзина и оформление заказов.
* SEO, аналитика, 3D-модели, интеграции с ClickHouse, очереди и др.

👉 Подробнее: раздел PLATFORM

***

### 🛠 Технологии

* Backend: PHP, Slim, ClickHouse, PostgreSQL/MySQL
* Frontend: Bootstrap 5.3, Alpine.js, чистый JavaScript
* API: REST-first
* Очереди, кеши, полнотекстовый поиск
* Docker, Redis, CI/CD
